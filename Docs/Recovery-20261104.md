## 설치 목록

1. **Unity Hub**: https://unity.com/download — Unity 로그인 후 사용 가능한 라이선스를 설정한다.
2. **Unity Editor 6000.4.3f1**: https://unity.com/releases/editor/whats-new/6000.4.3f1 — ProjectVersion.txt에 기록된 버전이다. 페이지에서 Hub로 설치한다. 우선 같은 버전으로 복구하고 버전 변경은 별도 작업으로 판단한다.
3. **Visual Studio Community**: https://visualstudio.microsoft.com/vs/community/ — 코드 편집·디버깅용 권장. 설치 관리자에서 `Game development with Unity / Unity를 사용한 게임 개발`을 선택한다. Windows IL2CPP 빌드 시 해당 C++ 도구/Windows SDK와 Hub의 Windows Build Support (IL2CPP)도 준비한다. Mono Windows 빌드에 IL2CPP 모듈이 항상 필요한 것은 아니다.
4. **GitHub Desktop**: https://desktop.github.com/download/ — 수동 커밋·Push/백업 확인용 권장. 이미 복제한 프로젝트를 Add Local Repository로 등록한다. 중복 Clone은 필요 없다. Codex 실행 환경의 Git으로 이번 복제를 완료했으므로 별도 Git for Windows는 필요할 때 설치한다.
5. **Obsidian**: https://obsidian.md/download — 이미 설치했다면 재설치하지 않는다. Open folder as vault로 이 프로젝트의 `Docs` 폴더를 연다. 이는 GitHub 문서를 활용하는 새 보관함이며, 잃은 개인 보관함 자체의 복원은 아니다.

Unity 패키지는 Packages/manifest.json과 packages-lock.json이 남아 있다. 인터넷 연결 상태에서 Unity가 이를 복원하게 한다. 캐릭터 PNG와 글꼴도 Assets에 포함돼 있다. 별도 에셋 구매나 Android Studio/Android SDK/JDK 설치는 현재 PC 목표의 선행 조건이 아니다. Node/Python/Blender도 현재 프로젝트를 여는 필수 조건으로 확인되지 않았다.

일반 설치 레지스트리와 기본 경로 확인에서는 Unity/Visual Studio/GitHub Desktop 설치를 찾지 못했다. 포터블·다른 경로 설치 여부까지 전수 확인한 결과는 아니므로 실제 설치 화면에서 중복 여부를 확인한다.
