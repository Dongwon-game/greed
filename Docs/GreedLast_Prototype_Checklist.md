# Greed Last 프로토타입 확인 순서

## 목적

- 지금 빌드는 완성 게임이 아니라 기획서의 핵심 체감인 `피하기 + 정확 타이밍 보상`을 확인하는 프로토타입이다.
- 그래픽이 입기 전까지는 레인, 중앙 액션 큐, 소리, 진동, 기록/흔적 흐름이 서로 같은 방향을 가리키는지 본다.

## 우선 체크

1. 로비 `흔적` 첫 페이지에서 `체감 목표`, `체크 n/7`, `루프 n/4`, `다음 확인`, `실행`, `Enter/강조`가 한 화면에서 같은 다음 행동을 가리키는지 본다.
2. 일반 런 첫 함정에서 중앙 액션 큐와 하단 상태줄이 `위험→동작→박자→보상`을 같은 표기로 말하는지 본다.
3. 일반 런 클리어 뒤 흔적 첫 페이지의 저장 상태가 `저장 후보 우선`, 무한 상태가 `후보 처리 후 무한`으로 보이고, 저장 후보를 저장하거나 포기한 뒤 다시 저장 조합에 들어갔을 때 같은 클리어의 저장 기회가 남지 않는지 본다.
4. 저장 조합을 두 번 사용해 자동 비움이 된 뒤 로비 / 저장 조합 / 무한 준비가 모두 `보충 런`, `무한 조합 보충`, `보충 안내`로 이어지는지 본다.
5. 기록 보드에서 저장 후보, 품질 비교, 테스트키, 상태줄 보상, `점수 +N`, `정박 중앙 집중 +N`, `자동 비움` 같은 안내가 빠지고 실제 점수 / 거리 / 구간 / 위협 / 콤보 / 실수만 남는지 본다.

## 기본 진입

1. Unity에서 `greed last` 프로젝트를 실행한다.
2. 필요하면 상단 메뉴 `Greed Last/Rebuild Boot Scene`으로 부트 씬을 다시 만들고, `Greed Last/Run Prototype Smoke Check`로 자동 스모크 검사를 실행한다.
3. 로비에서 `흔적`을 열고 첫 페이지의 `프로토타입 체크`와 4페이지의 `검증 순서`를 먼저 본다.
4. 첫 페이지의 `프로토타입 체크 - 기획 체감 검증`, `체감 목표: 피하기 + 정확 타이밍`, `체크 0/7`, `루프 0/4` 같은 진행 카운트가 일반 런, 저장, 소모, 자동 비움, 무한 기록 흐름에 맞춰 올라가는지 본다.
5. `루프 n/4`는 후보 대기에서 `루프 2/4`, 실제 저장 확정 뒤 `루프 3/4`, 첫 무한 기록 뒤 `루프 4/4`가 되는지 확인한다.
6. 4페이지 첫 순서가 `위험→동작·박자·보상·상태줄·루트 버튼`을 일반 런의 첫 확인 대상으로 잡고 있는지 본다.
7. 같은 줄의 `다음 확인:`이 `저장 후보 저장/포기`, `저장 조합으로 무한 시작`, `저장 조합 2회 소진`, `보충 후 무한 재진입`처럼 지금 비어 있는 확인 지점을 하나로 좁히고, `실행:`이 눌러야 할 버튼이나 테스트키를 같이 보여주며 로비 강조/Enter 경로와 같은지 본다.
8. `무한 복기 전 기초연습`처럼 무한모드 재도전 전에 손을 풀어야 하는 항목은 `실행: 복기 연습`으로, `무한 복기 재도전`은 `실행: 무한모드`로 갈라지는지 본다.
9. 검증 순서에 `위험→동작 바닥↑점 상단↓숙 측면↔틀`, `3동작 HUD`, `최근 흐름`, `중앙/레인 큐`, `큐 숨김`, `F8 경로 ↑↓↔·↔↓↑·↓↔↑`, `F9 동작`, `F1 무적`, `F2 기프트·F3 유물·F4 핵·F5 탈출`, `F6`, `PgUp`, `PgDn`, `End`, `위협 폭·보상`, `일시정지`, `소리%·진동 ON/OFF`, `터치 탭`, `자동 비움`, `완성 루프: 일반→저장→무한→기록`이 보이는지 확인한다.

## 일반 런

1. `일반 런` 시작 후 `2 / 1 / GO` 카운트인이 끝나고 첫 함정이 내려오는지 본다.
2. 에디터에서는 좌 / 중 / 우 레인에 `A/←`, `S/Space`, `D/→` 키 힌트가 보이는지 확인한다.
3. 모바일/릴리스 표기에서는 같은 레인이 `좌 탭`, `중 탭`, `우 탭`처럼 터치 대상으로 읽히는지 확인한다.
4. 하단 가이드가 `바닥→↑점프`, `상단→↓숙이기`, `측면→↔비틀기`처럼 위험군과 회피 기호를 같은 표기로 보여주는지 확인한다.
5. 활성 함정 근처에서 에디터는 `바닥 위험 → ↑ 점프 회피 · A/← · 1박 전 · 정확+...`, 모바일은 `바닥 위험 → ↑ 점프 회피 · 좌 탭 · 1박 전 · 정확+...`처럼 중앙 액션 큐가 위험군, 동작, 입력, 박자, 보상까지 한 줄로 보여주는지 확인한다.
6. 활성 목표 레인에는 `바닥→↑점프 · 충전+1`, `상단→↓숙이기 · 반격+50`, `측면→↔비틀기 · 연쇄+1`처럼 위험군, 회피 동작, 정확 보상이 같이 보이는지 확인한다.
7. 하단 상태 줄에 `바닥→↑점프 정확 +N / 보정 +N`처럼 위험군, 회피 동작, 정확 보상이 같이 남는지 확인한다.
8. 정확 입력을 이어가면 상태 줄에 `동작 ↑ 1/3→↓`, `동작 ↑↓ 2/3→↔`처럼 이번 묶음의 채운 동작과 다음 동작이 같이 보이는지 확인한다.
9. 점프 / 숙이기 / 비틀기를 모두 정확으로 지나면 흐름 태그가 `3동작 정확`으로 바뀌는지 확인한다.
10. 에디터 / 개발 빌드에서는 흐름 줄의 최근 패턴이 `좌정·바→점 > 중압·상→숙`처럼 레인, 박자, 위험군, 회피 동작을 같이 남기는지 확인한다.
11. 정확 입력은 `바닥→↑점프 회피`, Good은 `상단→↓숙이기 보정`, Miss는 `측면→↔비틀기 실패`처럼 위험군과 회피 품질이 같이 구분되는지 보고, 채널 오류나 입력 없음에는 에디터 `정답키 A/←`, 모바일 `정답 좌 탭` 같은 힌트가 붙는지 확인한다.
12. 코어 타이밍 직전 소리 큐와 점프 / 숙이기 / 비틀기 액션 큐가 함께 들리고, 충전 / 반격 / 연쇄 같은 특수 보상 타이밍에서 액션 큐가 살짝 더 또렷한지 확인한다.
13. 함정 마커가 점프는 낮고 넓게, 숙이기는 두꺼운 상단 압박처럼, 비틀기는 가늘고 기울어진 측면 공격처럼 구분되는지 본다.

## 일시정지

1. 런 중 `Esc` 또는 `P`로 일시정지를 건다.
2. 배경이 어두워지고 중앙 메뉴가 따로 뜨며 오른쪽 테스트 도구가 숨는지 본다.
3. 메뉴 배경 빈 곳을 눌러도 아래 레인이나 버튼이 반응하지 않는지 본다.
4. 일시정지 중 중앙 액션 큐가 메뉴 위에 남지 않는지 확인한다.
5. 다시 `Esc` 또는 `재개`를 누르면 `2 / 1 / GO` 후 첫 함정이 다시 읽기 쉬운 위치에서 시작하는지 본다.
6. 자동 진행이 켜진 상태에서 일시정지했다면 메뉴 중에는 멈추고, `GO` 뒤에는 다시 자동 진행 상태로 돌아오는지 본다.
7. 일시정지 메뉴나 런 오른쪽 보정 버튼에서 `빠름 +20ms`, `추천`, `늦음 -20ms`를 확인한다.
8. 같은 메뉴에서 `설정: 소리 N% / 보정 ... / 진동 ON/OFF` 상태 줄과 `소리 -`, `소리 100%`, `소리 +`, `진동 ON/OFF` 버튼이 보이고 런 중에도 오른쪽 테스트 패널에 표시되는지 본다.

## 테스트 단축키

1. `F1`: 무적 ON/OFF.
2. `F2`: 기프트 선택 구간.
3. `F3`: 유물 선택 구간.
4. `F4`: 공명핵 회수 직후.
5. `F5`: 탈출 직전.
6. `F6`: 런 중 집중 발동, 로비/성장판에서는 저장 생성 또는 포인트.
7. `F7`: 복기 목표 직전. 버튼에는 `목표 정산`, `목표 구간`, `목표 보정`처럼 목표 종류가 먼저 붙는다.
8. `F8`: 안정 / 변주 / 압박 경로 순환. 버튼에는 `경로 안정 ↑↓↔`, `경로 변주 ↔↓↑`, `경로 압박 ↓↔↑`처럼 다음 경로의 동작 배열이 붙는다.
9. `F9`: 점프 / 숙이기 / 비틀기 대표 함정 순환.
10. `PageUp` / `PageDown`: 무한 위협 상승/하강 또는 로비 저장 소모/후보 생성. 화면 버튼은 `PgUp` / `PgDn`으로 줄여 표시된다.
11. `End`: 무한모드 정산 종료. 정산 뒤 결과/복기 문구는 `정산 종료`로 읽혀야 하며 기록 화면에 `테스트 종료 기록`이 남으면 안 된다.
12. `End 정산 종료` 결과의 다음 행동은 `정산 종료 확인 후 무한모드 실전 재개`로 읽히고, Enter/강조도 무한모드 버튼으로 잡히는지 본다.
13. 첫 저장 전 로비에서는 `PgUp 저장 없음`, 저장 조합이 전부 비어 보충이 필요한 상태에서는 `PgUp 보충 확인`으로 갈라지는지 본다.
14. 첫 저장 전 `PgUp` 알림은 저장 생성을 먼저 안내하고, 자동 비움 뒤 `PgUp` 알림은 무한 버튼의 보충 런을 안내하는지 본다.

## 저장 조합

1. 일반 런 클리어 후 바로 저장 슬롯 선택 화면이 뜨는지 확인한다.
2. 클리어 직후 하단 버튼이 `저장 슬롯 선택`과 `저장 없이 로비`로 갈라져 보이고, 저장 슬롯 화면에서 `선택 전 저장 잠김`이 보인 뒤 원하는 슬롯에 들어가는지 본다.
3. `저장 없이 로비`로 돌아오면 클리어 요약이 로비에 남고 기록 버튼이 `클리어 복기`로 바뀌는지 확인한다.
4. 저장 후보를 확정하거나 포기하면 `저장 후보 없음`으로 바뀌고, 다시 로비/저장 조합에 들어와도 같은 클리어의 저장 기회가 남지 않으며 새 저장은 다음 클리어 후 1회만 가능하다고 보이는지 확인한다.
5. 기존 슬롯이 있는 상태에서 새 후보가 생기면 흔적과 저장 조합 화면에 `후보 비교 후 저장/포기`, `저장 버튼: 덮어쓰기 확인 / 포기 버튼: 후보 소모`가 보이는지 확인한다.
6. 저장 조합은 무한모드에서 2회 사용 후 자동으로 비워져야 한다.
7. 저장 슬롯과 무한 준비 화면에서 `2/2`, `1/2`, `자동 비움`, `시작 후 비움` 흐름이 읽히는지 확인한다.
8. 무한 결과 메시지에 첫 사용 후 `마지막 1회 (1/2)`, 최종 소모 뒤 `자동 비움`과 `무한 조합 보충`이 이어지는지 본다.
9. 자동 비움 뒤 흔적의 `프로토타입 체크`에 `최근 소진 자동 비움`이 보이고, 저장/성장 페이지에는 `무한 조합 보충 필요`가 보이는지 본다.
10. 저장 조합이 비어 있는 로비/저장 조합 관리/무한 준비/슬롯 선택 화면에서 `보충 런`, `무한 조합 보충`, `보충 안내`, `보충 런 버튼: 보충 런 진입`, `다음: 보충 런 클리어 후 새 조합 저장`이 보이고, 선택 전 화면도 빈 슬롯 선택 대신 보충 런 안내로 읽히는지 본다.
11. `다음: 보충 런...`, `다음 확인: 보충 런...`, `보충 후 무한 재진입` 문구가 보이면 로비 강조/Enter가 일반 런이 아니라 무한 조합 보충 버튼으로 이어지는지 본다.
12. 저장 후보가 남아 있으면 화면에 `보충 런...`이나 `보충 후 무한 재진입`이 같이 보여도 Enter/강조는 먼저 `저장 조합`으로 가는지 본다.
13. 빈 슬롯을 눌러도 `선택 완료`가 아니라 보충 런 안내가 유지되는지 본다.
14. 로비 저장 소모만으로 슬롯이 먼저 비었을 때도 `다음 확인:`이 `무한 기록 생성`보다 `보충 후 무한 재진입`을 우선 안내하는지 본다.
15. 저장 후보가 남아 있는 동안 흔적 4페이지의 무한모드 순서가 `후보 처리 후 시작`으로 보이고, 자동 비움 뒤에는 저장 조합 순서가 `보충 클리어 후 저장`으로 보이는지 본다.
16. 보충 런 클리어 뒤 저장하지 않고 나가면 `보충 런 저장 안 함`, `저장 조합은 갱신되지 않았습니다`, `기록:` 한 줄만 남고 저장 후보/판정 상세가 다시 뜨지 않는지 본다.

## 무한모드

1. 저장 조합으로 무한모드에 들어가면 조합 이름과 효과가 실제 선택/보상에 이어지는지 확인한다.
2. 무한모드 준비 화면과 저장 조합 상세에 `입장 체크: 위협 폭·보상 / PgUp·PgDn`이 보이고, 짧은 준비 요약에는 `위협 체크`가 남는지 확인한다.
3. `PageUp` / `PageDown` 또는 오른쪽 버튼으로 위협 단계를 바꿔 상단 진행 바와 하단 가이드에 `위협 1/5 안정 폭좁음 정확+0`에서 `위협 5/5 최고 폭최대 정확+...`처럼 위험 폭과 보상 변화가 같이 보이는지 본다.
4. 종료 후 무한 기록의 다음 목표가 위협 진입이면 `폭·보상 확인`까지 같이 붙어, 다음 무한 재도전에서 무엇을 읽어야 하는지 바로 보이는지 확인한다.
5. 종료 후 무한 기록에는 점수, 거리, 구간, 등급, 최고 위협, 콤보, 실수만 남고 코칭 문구나 `정답키`, `정답 좌 탭`, `터치 탭` 같은 조작 힌트가 섞이지 않는지 확인한다.
6. 무한 기록이나 일반 기록 줄에 `저장 조합 소모`, `사용 결과`, `남은 사용`, `다음 소모 후 슬롯 자동 비움` 같은 소모 알림이 기록값처럼 섞이지 않는지 확인한다.
7. `End 정산 종료`로 만든 무한 결과도 기록 보드에서는 `정산 종료 기록`, `실제 생존 흐름`, `실제 플레이` 안내가 빠지고 점수/콤보 같은 기록값만 남는지 확인한다.
8. `End 정산 종료` 직후 로비/흔적의 다음 행동은 복기 약점보다 `무한모드 실전 재개`를 우선 안내하는지 확인한다.
9. 단, End로 복기 목표를 달성한 경우에는 `목표 상향` 안내가 실전 재개보다 먼저 보이는지 확인한다.
10. `정산 종료 확인 후 무한모드 실전 재개` 결과에서는 무한 버튼이 `무한 실전 재개`로 읽히고, 준비 화면에는 `정산 종료 확인 완료` 안내만 짧게 보이며 연습 버튼/준비 화면에는 `무한 복기 재도전` 문맥이 섞이지 않는지 확인한다.
11. 실제 `무한 복기 재도전` 결과에서 무한 준비 화면으로 들어간 뒤 저장 조합 변경, 기프트/유물 정비를 거쳐도 `목표: 다음 구간...` 문맥이 시작 전까지 유지되는지 확인한다.

## 기록과 흔적

1. `무한 기록`은 기록만 깔끔하게 보여야 하며 조작 힌트, 저장 후보, 저장 관리 문구가 남으면 안 된다.
2. `흔적` 첫 페이지는 일반 / 저장 조합 / 무한 / 성장 / 중앙/레인 큐 / 자동 비움 / 복기 다음 행동을 짧게 보여야 한다.
3. `흔적` 장식 페이지는 점프 / 숙이기 / 비틀기 숙련을 보여주되 기록 보드를 더럽히면 안 된다.
4. 흔적의 `실행:`, 로비의 강조 버튼, Enter 기본 행동이 같은 다음 행동으로 이동하는지 본다.

## 빠른 회귀 순서

1. 로비에서 `흔적`을 열어 `체감 목표`, `체크 n/7`, `루프 n/4`, `다음 확인`, `실행`, `Enter/강조`가 한 화면에 잡히는지 본다.
2. `일반 런`으로 들어가 첫 활성 함정에서 레인 라벨, 중앙 액션 큐, 하단 상태줄이 모두 `위험→동작→박자→보상`을 같은 표기로 말하는지 본다.
3. `F4 핵 직후` 또는 `F5 탈출 직전`으로 클리어 흐름을 빠르게 만들고, 저장 슬롯 선택 화면에서 먼저 슬롯을 골라야 저장이 풀리는지 확인한다.
4. 저장하지 않고 로비로 나갔을 때는 `클리어 복기`와 기록 보드만 남고, 저장 조합 슬롯은 비어 있는지 본다.
5. 다시 클리어해 저장 후보를 만들고 슬롯에 저장한 뒤, 저장 조합 화면에 `저장 후보 없음`과 `다음 클리어 후 1회`가 떠서 같은 클리어를 다시 저장할 수 없는지 본다.
6. 무한모드 준비에서 `입장 체크: 위협 폭·보상 / PgUp·PgDn`과 마지막 1회 `시작 후 자동 비움` 경고를 확인한다.
7. 저장 조합을 두 번 사용해 자동 비움이 된 뒤 로비, 저장 조합, 무한 준비 화면이 모두 `보충 런`, `무한 조합 보충`, `보충 안내`로 같은 동선을 가리키는지 본다.
8. 기록 보드 4페이지를 넘기며 저장 후보, 품질 비교, 테스트키, 액션 큐, 보정, 복기 약점 같은 안내가 빠지고 점수/거리/구간/콤보/실수만 남는지 본다.

## 이번 작업에서 새로 볼 것

- 흔적 첫 페이지에 에디터는 `중앙/레인 큐+상태줄 확인: 위험→동작·키·1박·보상`, 모바일/릴리스는 `위험→동작·탭·1박·보상` 계약이 보이는지.
- 흔적 첫 페이지의 `체크 n/7`과 `루프 n/4`가 일반 런, 저장 조합, 2회 소진, 무한 기록을 지나며 올라가고, `저장 후보 우선` 상태만으로 완성 루프의 저장 단계가 완료 처리되지 않는지.
- 저장 후보가 남아 있는 동안 흔적 첫 페이지에 `저장 후보 우선`과 `후보 처리 후 무한`이 보이고, 화면에 보충/무한 문구가 같이 있어도 Enter/강조는 먼저 `저장 조합`으로 가는지.
- 저장 후보가 남아 있는 로비 / 클리어 결과 / 저장 조합 화면에서 다음 행동이 `저장 또는 포기`, `첫 슬롯 저장 또는 포기`, `저장 버튼: 이 슬롯 저장 / 포기 버튼: 후보 소모`처럼 저장과 포기 양쪽으로 읽히는지.
- 흔적 첫 페이지의 `다음 확인:`이 현재 진행 단계에서 바로 눌러 볼 확인 지점을 하나로 좁히고, 옆의 `실행:`이 눌러야 할 버튼/테스트키를 같이 보여주며 로비 강조/Enter 해석과 어긋나지 않는지. 저장 조합 최종 소모 단계는 `실행: PgUp 소모`로 보이는지.
- `무한 복기 전 기초연습`은 복기 연습으로, `무한 복기 재도전`은 무한모드로 갈라져 같은 `무한` 문구라도 목적지가 다르게 잡히는지.
- 에디터 런 레인에 `A/←`, `S/Space`, `D/→` 입력 힌트가 보이는지.
- 모바일/릴리스 런 레인에 `좌 탭`, `중 탭`, `우 탭` 터치 힌트가 보이는지.
- 모바일/릴리스 중앙 액션 큐와 실수 피드백에도 `좌 탭`, `중 탭`, `우 탭` 정답 위치가 레인별로 붙는지.
- 기초연습 완료 화면에서 실패는 `측면→↔비틀기 실패`, Good은 `상단→↓숙이기 보정`, 전부 정확은 `바닥→↑점프 · 상단→↓숙이기 · 측면→↔비틀기 정확`처럼 위험군과 회피 동작을 함께 보여주는지.
- 결과 화면은 `상단→↓숙이기 실수 1회 / 기초연습 숙이기 단계`처럼 위험군과 복기 이동 단계를 풀어서 보여주고, 흔적 첫 페이지는 `복기 약점 상단→↓숙이기 실1 / 연습 숙이기`처럼 압축해 첫 페이지가 지저분해지지 않는지.
- F8 경로 확인 버튼이 `경로 변주 ↔↓↑`, `경로 압박 ↓↔↑`, `경로 안정 ↑↓↔`처럼 다음 경로의 대표 동작 배열을 같이 보여주는지.
- F9 동작 확인 버튼이 `동작 ↑ 점프`, `다음 ↓ 숙이기`, `다음 ↔ 비틀기`처럼 중앙 회피 기호와 같은 표기를 쓰는지.
- F2~F5 오른쪽 테스트 버튼이 `F2 기프트 선택`, `F3 유물 선택`, `F4 핵 직후`, `F5 탈출 직전`으로 보이고 각 구간으로 바로 이동하는지.
- F7 복기 목표 버튼이 `목표 정산`, `목표 구간`, `목표 보정`처럼 목표 종류를 먼저 보여주는지.
- 채널 오류 / 입력 없음 피드백에 `정답키` 힌트가 붙는지.
- 검증 순서와 일시정지 메뉴에서 입력 보정 `빠름 / 추천 / 늦음`을 확인할 수 있는지.
- 검증 순서에는 `감각 소리%·진동` 계약이, 흔적 첫 페이지에는 `감각 보정:0ms·소리100%·진동ON`처럼 현재 입력 보정, 소리 볼륨, 진동 상태가 보여 테스트를 놓치지 않는지.
- 소리 표시가 0% 아래나 100% 위로 튀지 않고 `소리 0%`~`소리 100%` 사이로 고정되며, 입력 보정도 흔적에서 `-200ms`~`+200ms` 안으로 보이는지.
- 무한모드에서 `PgUp` / `PgDn`을 눌렀을 때 상단 진행 바와 하단 가이드가 모두 `위협 n/5`, `폭`, `정확+` 보상을 같이 바꾸는지.
- 오른쪽 테스트 버튼 라벨이 `F1`, `F6`, `PgUp`, `PgDn`, `End`, `F7~F9`처럼 키와 함께 표시되는지.
- 흔적 화면 가운데 레인이 `기록 보드`로 보여지고, 누르면 최근 진행이 일반이면 일반 기록, 무한이면 무한 기록으로 바로 이동하는지.
- 일시정지 배경이 아래 입력을 차단하고, 자동 진행은 메뉴 중 멈췄다가 `GO` 뒤 복구되며, 카운트다운 / 선택 / 정산 중 중앙 액션 큐가 숨겨져 화면을 가리지 않는지.
- 기록 / 흔적 페이지의 이전·다음 버튼에 `2/4 일반 기록`, `4/4 검증`처럼 페이지 번호와 목적지가 같이 보이는지.
- 흔적 4페이지 검증 순서에 `2/4 버튼`, 조작 체크에 `일시정지·선택·정산 큐 숨김`, `터치 탭`이 보이는지.
- 흔적 4페이지 조작 체크에 `완성 루프: 일반→저장→무한→기록`이 보여 프로토타입 완성 기준이 한 바퀴로 잡히는지.
- `루프 4/4` 이후 급한 저장 소모/보충/복기 체크가 없으면 로비 중앙에 `프로토타입 완성 루프 확인`이 보이고, 흔적 버튼이 `흔적 완성 NEW`로 보이며, 흔적의 `Enter/강조`는 `기록 보기`, `다음 확인: 완성 루프 기록 확인`은 `완성 기록` 버튼과 기록 요약 페이지로 이어지고 흔적 가운데 기록 바로가기도 요약 페이지로 열리는지.
- 로비의 `완성 기록`으로 기록 요약을 확인한 뒤에는 `흔적 완성 NEW`가 계속 남지 않고 확인된 흔적으로 정리되는지.
- 흔적 4페이지의 무한모드 순서에 `위협·정산·실전 재개`가 보여 End 정산 종료 뒤 실제 무한 런으로 돌아가는 확인 지점이 보이는지.
- `루프 4/4`가 된 뒤 흔적 장식/배지 페이지의 획득 배지에 `완성 루프`가 보이는지.
- 저장 조합 슬롯에서 `2/2 · 2회 남음`, `마지막 1회 (1/2)`, `자동 비움`, `시작 후 비움` 순서가 끊기지 않는지.
- 무한 준비 화면에서 마지막 1회 슬롯은 `이번 시작 후 이 슬롯은 자동으로 비워집니다.` 또는 `시작 후 자동 비움`을 보여주는지.
- 저장 후보를 확정한 뒤 다시 저장 조합에 들어가면 `저장 후보 없음`과 `다음 클리어 후 1회`만 보이고 같은 클리어를 다시 저장할 수 없는지.
- 기록 보드에는 저장 후보/저장 관리/테스트키/상태/판정/사용 흐름/조작 힌트/상태줄/3동작 HUD/`위험→동작`/`바닥→↑점프`/`다음 확인:`/`실행:`/`흔적 완성 NEW`/`루프 n/4`/`2/4 버튼`/성장 포인트/입력 보정/소리/진동 같은 안내가 빠지고 점수, 거리, 구간, 위협, 콤보, 실수 같은 기록값만 남는지.
- 기록 보드에 `2/4 점검`, `완료 1회`, `보정 100ms`, `입력 보정 0ms`처럼 숫자는 있지만 기록 단위가 아닌 설정/체크 문구가 남지 않는지.
- 기록 보드에 저장 후보 요약, 현재 품질, 품질 차이, 조합 요약처럼 점수와 숫자가 들어간 저장 비교 줄이 기록처럼 섞이지 않는지.
- 기록 보드에 `비교: 최고 대비`, `점수 +120`, `거리 +8.0m`, `체력 +1`, `집중 -1`, `정확률 +20%p`처럼 결과 비교 델타가 독립 기록처럼 섞이지 않는지.
- 기록 보드에 `바닥→↑점프 정확 +N`, `정박 중앙 집중 +N`, `압박 반격 +N`, `엇박 연쇄 +N`처럼 런 중 보상 코치가 점수 기록 옆에 붙어 남지 않는지.
- 기록 보드에 `성과 요약`, `클리어율`, `루프 n/4` 같은 흔적 요약 통계가 기록처럼 섞이지 않는지.
- 기록 보드에 `자동 진행`, `자동 정지`, `자동 비움`, `GO 뒤 자동 진행 복구` 같은 상태 전환 문구가 기록처럼 섞이지 않는지.
- 기록 보드에 `복기 약점`, `무한 약점`, `연습 점프/숙이기/비틀기`, `기초연습 ... 단계`, `보정:` 같은 테스트 안내가 섞이지 않고 점수/콤보만 남는지.
- 일반 기록 페이지에 클리어와 실패/중단 기록이 많이 쌓여도 상위 클리어와 최근 시도만 짧게 보이고 5~6줄짜리 긴 목록으로 늘어나지 않는지.
- `흔적 성장 NEW`, `흔적 저장 NEW`, `흔적 보충 NEW`를 눌렀을 때 요약 대신 저장/성장 흔적 페이지로 바로 들어가는지.
- 저장 후보가 남아 있을 때 무한 버튼이 `무한 후보 저장 필요`로 막히고, 보충 런 결과는 `보충 기록`으로 확인되는지.
