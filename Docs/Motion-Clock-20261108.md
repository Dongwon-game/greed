# 누적 시간 뒤 주행 움직임 유지

실제 `Update`는 `beatPhase`에 프레임 시간을 계속 더하지만, 달리기 보폭·바닥 타일·기둥·통로의 일곱 계열은 이를 `Clamp01`로 1에 고정하고 있었다. 따라서 첫 구간의 속도 대조만 통과해도 이후 기본 움직임이 고정될 수 있었다. 기존 아트·채널 대응·판정·보상 설계와 별개인 표시 계산 오류다.

`f1d9fdc`에서 아홉 위상 함수에 1 경계, 2.25 이후, 100.25 이후의 진행과 비주행 게이트를 추가했다. 실제 Unity 스모크 `a1cc3341ab4a40fbb296589a71c83c76`에서 `BuildStraightRunCorridorGatePhase must keep advancing…` 오류를 재현했다. 보고서 SHA256 `1888C4F773C63A280EC25DE3114BD4688F79944F0CA83F1D9868823F7D653BD9`, 개인·원본 설정 불변이다.

`438721e`는 아홉 함수가 음수만 제한하고 누적 시간을 속도에 적용한 뒤 순환하도록 고쳤다. 이전 속도/보상 강조와 비주행 게이트는 유지한다. 전체 스모크·Windows 후보가 통과했다. 보고서 `86d684c94bf04105b862ceeef7b81062`, SHA256 `55625D7BC68D10D3D6589D229A3A6F3BF10453BEF5E810C516C191131D93A2B8`, 개인·원본 설정 불변이다.

`43d2366`의 플레이어 관찰기는 실제 첫 연습에서 같은 함정·체력·Miss를 유지하며 8개 엔진 프레임의 누적 시계·바닥·기둥 좌표를 기록한다. 코어 시계나 UI Update를 수동 호출하지 않는다. 시계 6.3598→6.5465 동안 바닥 Y 0.7200→0.6801, 기둥 Y 0.5348→0.5070으로 실제 이동했고, 카메라 16장·저장/재실행 10단계·안전 대조 4개가 통과했다. 보고서 `ffdb607a7d394053bc4cea3d69e3e5fe`, SHA256 `4A430F295E3AA96D0E52348ABDBCAF74A52F32215EBFE7F4A1FFF962F9746644`, 개인·원본 설정 불변·소유 프로세스 종료다.

두 Play Mode 조건은 실행 중이다. 추가로 누적 시계가 큰 상태에서 속도 값이 조금 내려갈 때 위상이 역행/급변하는지 스모크 경계를 추가했다. 이 후속은 검증 중이며, 앞선 기본 움직임 성공을 속도 전환의 성공으로 확대하지 않는다. 실제 청음·손맛도 별도다.
