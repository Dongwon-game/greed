복기 상태에 따라 연습 버튼 이름이 달라지는 경우를 고려해 입구 안내를 ‘연습 버튼’으로 통일했다. 기존 스모크 기대값에 PC Enter 안내와 모바일 문구 분리를 추가했다. 작업 위치 문서는 11월 4일 소스, 11월 5일 검토 후보, 11월 6일 검증 대기 변경을 구분한다. 이 단계까지 화면 조작, 컴파일, 빌드, 검사 실행을 보류했다.

PC 체험 안내에 최신 6-3 1Node의 선택 순서를 반영했다. 1~3장 루트와 마감 기프트, 2장 마감 기프트 뒤 유물, 4장 공명핵과 탈출을 구분한다. 소스의 분기를 읽어 작성했으며 이번 실행에서 일반 런을 재현하지 않았다.

프로필과 기록의 다음 버튼에는 기존 플랫폼 정책에 따라 Enter 표기를 붙였다. 기록 본문과 페이지 전환 동작은 기존 경로를 사용한다. 기존 스모크의 버튼 기대값을 갱신했으며 컴파일·스모크·창 검증은 보류했다. 다음 확인에서 1280×720의 긴 프로필 버튼 문구와 4→1 순환을 확인한다.

비개발 빌드의 입력 경로에서 Q/E가 회전 명령을 실행하지 않으면서 처리 완료를 반환해 같은 프레임의 채널 입력까지 건너뛸 수 있었다. 회전 개발 키의 활성 조건을 먼저 확인하도록 옮겼다. 이후 비개발 후보에서 Q/E 단독으로 동작이 없고, 같은 프레임의 A/S/D가 정상 전달되는지 확인한다. 개발 빌드의 회전 구간 Q/E와 Alt+Enter도 별도 대조한다. 이번에는 실행하지 않았다.

개발 빌드에서도 활성 회전 패턴이 없는 구간의 Q/E는 다음 입력 처리를 막지 않도록 했다. 활성 회전 구간의 Q/E는 기존 채널 처리로 연결된다. 정지 중에는 기존 채널 입력 차단을 따른다.

## 검증을 재개할 때

각 결과에 확인한 Git 커밋과 실행본을 기록한다. 아래 항목은 현재 작업 브랜치에서 모두 대기 상태다.

| 화면 | 입력과 확인 기준 |
| --- | --- |
| PC 첫 입구 | 1280×720에서 시작 문구를 읽고 Enter로 연습에 진입한다. 화면의 연습 버튼도 같은 시작 경로를 제공한다. |
| 프로필 및 기록 | 다음 버튼의 Enter가 잘리지 않고, 각 보드에서 Enter가 페이지를 한 장씩 넘긴다. 프로필 4/4에서 로비 추천 문구를 읽고 페이지 이동과 구분한다. 점수·콤보는 기록 행에서 대조한다. |
| 프로필 동시 입력 | 같은 프레임의 A+Enter는 이전 페이지로 이동하고 S+Enter는 기록을 연다. Enter만 눌렀을 때는 다음 페이지로 이동한다. |
| 일반 채널과 개발 회전 | 비개발 후보에서 Q/E가 같은 프레임의 A/S/D를 가로채지 않는지 확인한다. 개발 환경에서는 회전 구간과 일반 함정에서 Q/E의 경로를 각각 확인한다. 같은 프레임 여부를 관찰할 수 없으면 동시 입력 항목은 대기로 남긴다. |
| 저장 및 무한 | 격리 저장으로 슬롯 선택과 별도 확정, 정비 취소 무소모, 두 번 시작 후 자동 비움을 확인한다. 일반 런은 루트 3·기프트 4·유물 1 순서와 탈출 뒤 결과를 확인한다. |
| 성장 | 같은 프레임의 방향 키와 Enter를 합성 입력으로 대조한다. 명시한 트랙만 한 번 강화하며 추천 트랙에 포인트가 먼저 쓰이지 않아야 한다. 별도 Enter는 기존 추천 강화 경로를 사용한다. |
| 런 선택 | 입력이 열린 선물·경로·유물 화면에서 같은 프레임의 방향 키와 Enter로 해당 선택이 한 번 적용되는지 확인한다. 일시정지 중 Enter 재개와 일반 함정 중 Enter 동작도 대조한다. |
| 함정 접근 원근 | 좌·우 함정과 접근 잔상, 박자 눈금이 멀리서는 중앙에 가까우며 판정 지점까지 제 레인 폭으로 펼쳐지는지 본다. 함정 그림은 작게 나타나 판정 지점에서 기존 크기로 돌아온다. 스모크에서 먼 바닥 함정의 시작 위치와 기존 판정 지점 보존을 대조하고, 실제 화면에서 좌·우가 멀리서도 구분되는지 확인한다. |
| 집중과 주행 표시 | 같은 일반 런에서 집중 발동 전후로 Good 띠가 목표 레인과 판정 시간 범위를 유지하는지 본다. 함정이 없는 구간에서는 집중 강조가 보이는지 확인한다. 먼 함정 그림은 발광에서 구분되고 판정 직전에는 기존 밝기로 돌아와야 한다. 바닥의 기본 안내와 박자 강조를 각각 대조한다. 이번 작업에서는 실행하지 않았다. |
| 함정 사이 판정선 | 플레이 보기에서 다음 함정을 기다리는 동안 옅은 기준선이 보이고, 새 함정이 시작되면 대상 레인의 밝은 판정선으로 이어지는지 본다. 판정 직후 펄스와 일시정지·카운트다운을 각각 대조한다. |
| 직접 체감 | 본문 및 손잡이 드래그, 포커스 복귀 후 새 입력, 가청 소리와 판정 타이밍을 확인한다. 드래그의 근거는 드래그 시작 이후 콘텐츠 이동이다. |

50% 남음 체크포인트는 같은 300분 창의 실제 47% 남음 조회에서 기록했다. 프로필에서 추천한 버튼과 로비 복귀 직후의 Enter 대상이 달라질 수 있어 추천 문구를 ‘로비 추천 버튼’으로 구분했다. 프로필의 Enter는 다음 페이지이며 로비의 실제 입력 경로는 그대로다. 기존 안내 형식을 읽는 호환 분기를 보존했고 기록 정리는 새 추천 문구도 제외한다. 문구·스모크 검사 기대값을 갱신했으며 실행은 대기다. 다음에는 프로필에서 추천을 읽고 로비로 나왔을 때 명시된 버튼을 선택하는 흐름을 확인한다.
