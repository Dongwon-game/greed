# PC 종료와 방향키 안내

사용자 직접 플레이 뒤 요청: 시작 전 ESC 종료, 런 중 ESC 메뉴의 로비 복귀·게임 종료, 가운데 대응의 아래 방향키 안내.

↓는 이미 실제 가운데 입력과 눌림 표시에 연결돼 있었다. 표시를 S/↓로 바꾸고 기존 입력 호환은 유지한다. 로비의 하단 버튼은 게임 종료 (ESC), 정지 메뉴는 재개·메뉴로 돌아가기·게임 종료를 제공한다. 런 중 ESC는 정지/재개이며 정상 주행 중 종료 요청은 허용하지 않는다. 재개 카운트와 입력 중단 상태도 종료 버튼을 차단한다. 종료는 기존 Application.Quit 경로이며 저장 초기화·슬롯 소모 코드는 추가하지 않았다. 로비로 돌아갈 때의 기존 중단/정산 규칙은 유지한다.

작업 소스 f7026ff와 검사 접근 수정 0456db4. 기존 878b01c 후보는 이 요청 전 실행본이다. 첫 검사 5467cb8e459b490fa629cacaaf9b3460은 Editor 검사에서 내부 메서드를 직접 호출해 컴파일 실패했고, 기존 반사 접근 방식으로 수정했다. 후속 6e0b68ef1edc4a64aa7559b23c368e94의 전체 스모크·Windows 후보를 확인 중이다. 아직 새 실행본의 실제 ESC 종료/정지 메뉴 클릭 통과를 주장하지 않는다.
