# Greed Last 구현 기준

짧은 직접 확인은 [프로토타입 빠른 확인](GreedLast_Prototype_QuickCheck.md), 세부 회귀와 그래픽 비교는 [전체 체크리스트](GreedLast_Prototype_Checklist.md)를 따른다.

원본 기획과 현재 체감/간소화/남은 실기기 확인의 대조는 [기획 체감 범위](GreedLast_Prototype_PlanCoverage.md)를 따른다. 원본과 다른 집중 보호도 같은 규칙으로 표시하지 않고 별도 판단 대상으로 남긴다.

## 2026-10-13 글자 완전성과 캡처 보존

- 화면 검사에서는 남은 글자의 좌표뿐 아니라 실제 축소 글꼴 크기에서 수직 잘림을 제거한 글자 수와 비교한다. 한글/여러 줄/서식 태그/정상 축소는 허용하고, 일부 줄이 사라진 문구는 좌표가 영역 안에 있어도 거부한다. 게임 문구나 글꼴 크기를 임의로 바꾸는 기능은 아니다.
- 프리뷰 캡처는 실행마다 새 `Logs/VisualChecks/capture-...` 폴더에 저장하고 파일 생성 전용으로 써서 이전 이미지/같은 이름을 덮어쓰지 않는다. 보고서의 이미지 경로는 VisualChecks 기준 상대 경로이며 `latest-report.json`만 최근 결과 색인으로 갱신한다.
- 렌더 이후 검사가 실패하면 해당 프리뷰 PNG도 보존한다. 아직 렌더하지 못한 단계의 오류에는 이전 화면을 실패 사진으로 저장하지 않는다. 잘림 거부 검사는 정상 대조 한 장과 의도적으로 잘린 버튼을 구분하며 실패 메시지/이미지를 보고서에 따로 남긴다.
- 피격/눌림 강조로 보이는 레인이 자신의 투명 확장 입력 영역 위에 겹칠 수 있다. 프리뷰 입력 검사는 등록된 레이캐스터 안에서 같은 채널의 두 표면만 허용하고 실제 마우스/합성 터치의 채널 콜백을 확인한다. 다른 채널 대체는 콜백을 바꾸기 전에 거부하며 확장/겹침 검사 수를 별도로 기록한다. 게임 입력 영역은 바꾸지 않는다.
- 캡처 보고서 저장에 실패해도 임시 자원 정리를 시도하고 실패 종료를 유지한다. 보고서/정리의 네 메모리 실패 조합은 순서/실패 상태 정책만 확인하며 실제 파일시스템 장애나 실제 씬 제거의 재현으로 표시하지 않는다.
- 이 검사는 격리 프리뷰 카메라·합성 코어 스냅샷/수동 UI Update이다. 실제 엔진 전체 런·손 입력/실제 스피커·휴대폰 지연/FPS와 구분하고 게임 규칙·개인 데이터·실행 빌드는 유지한다.

## 2026-10-13 함정 예고 발행 경계

- 판정 후 비활성 상태와 다음 함정이 UI Update 사이에 발행되면 이전 함정의 진입/타이밍 예고 재생 표시가 남을 수 있다. 새 실행·비활성/정지·선택·카운트, 새 함정 ID 또는 되감긴 함정 시간은 발행 단계에서 해당 표시를 먼저 비운다. 실제 예고 재생은 기존 표시 Update에서만 처리한다.
- 같은 활성 함정의 반복 스냅샷/F11 갱신에는 재생 표시를 유지해 중복 예고를 만들지 않는다. 기본/상세 모두 같은 규칙이며 판정·점수·집중 보호·재개 여유·저장/사용권·개인 설정은 바꾸지 않는다.
- 편집기 격리 검사는 실제 코어의 합성 Tick/판정→비활성→다음 함정 발행을 중간 UI Update 없이 비교한다. 엔진 검사는 Update가 끝난 LateUpdate에서 실제 시간의 공개 입력/다음 함정 명령을 같은 프레임에 실행하며 기본/상세와 두 재생 방식을 비교한다. 이어 같은 함정의 정지→새 재개 카운트 중 값/예고 미소비와 기존 여유 뒤 진입·타이밍 표시 복구도 확인한다. 실제 기기 FPS·스피커 소리/지연 검사로 확대하지 않는다.

## 2026-10-12 입력 시스템 소유권과 재활성화

- 화면 입력은 활성 EventSystem과 활성·지원되는 입력 모듈이 함께 있는 경우에만 빌린다. 비활성 시스템/모듈이나 모듈 없는 외부 오브젝트를 임의로 켜거나 고치지 않고, 앱 소유의 Legacy 입력 시스템으로 복구한다. Unity의 현재 입력 대상으로 설정해 보이는 버튼의 마우스/터치가 실제로 처리되게 한다.
- 씬 인계 때 사용할 수 있는 외부 입력이 생기면 기존 누름을 취소하고 자체 입력만 해제한다. 외부 입력이 사라지면 자체 입력을 다시 만든다. UI 재활성화에도 카메라·소리 수신기·입력을 확인하며, 그 사이 외부 모듈이 멈췄어도 정지된 런을 자동 재개하지 않는다.
- 앱 제거 때 자신의 입력 오브젝트는 비활성화 후 해제한다. 빌린 입력의 기존 키보드 내비게이션 값만 복원하고 외부 활성 상태·모듈·나중에 외부에서 켠 내비게이션을 건드리지 않는다. 비활성/모듈 없는 외부 EventSystem 자체를 삭제하지 않으므로 의도적으로 잘못 구성한 검사 씬에는 복수 시스템 경고가 남을 수 있다. 정상 부트에서는 하나만 사용한다.
- 엔진 격리 검사는 외부 비활성 시스템/비활성 모듈/모듈 없음/정상 대여 네 경우, 두 실제 씬 인계와 UI 재활성화 복구, 실제 EventSystem의 합성 마우스·터치 명령을 비교한다. 개인 데이터·판정·재개 여유·저장 한 번/실제 두 번 시작 규칙은 유지한다. 하드웨어 입력/휴대폰 센서·지연 검사가 아니다.

## 2026-10-12 단축키 눌림 표시

- Ctrl/Alt/AltGr/시스템 키가 눌린 동안 명령 차단과 레인 눌림 표시가 같은 키보드 정책을 사용한다. 처리되지 않은 시스템 단축키가 게임 레인을 누르는 것처럼 보이면 안 된다. 일반/Shift 호환 입력과 실제 터치 눌림은 유지한다.
- 표시 검사는 여덟 수식 키 조합에서 실제 눌림 배열·표시 강도와 별도 터치 유지·새 기본 키 복구를 비교한다. 합성 표시 상태 콜백이며 OS 키 입력이나 새 이미지 검사로 표시하지 않는다.

## 2026-10-11 전역 표시 설정의 수명

- 앱 시작 전에 품질 단계·vSync·목표 프레임·화면 절전 요청을 보관하고 실행 중에는 기존 0/60/NeverSleep을 유지한다. 앱 제거 때 현재 값이 우리 적용값과 같은 항목만 원래 값으로 돌린다. vSync는 원래 품질 단계가 그대로일 때만 복원하며, 다른 품질 단계로 바뀌었으면 새 단계의 값이나 품질 선택을 건드리지 않는다. 이전 비활성 품질 단계를 복원하려고 다시 선택하지 않는다. 반복 해제나 초기화 전 제거도 다른 설정을 바꾸지 않는다.
- 정지/재개 중에는 이 설정을 해제하지 않는다. 실제 타이밍·보상·개인 선호/진행도·저장/사용권과 모바일 방향 설정을 바꾸지 않는다. 실제 FPS나 휴대폰 절전/방향 동작을 측정한 수정이 아니다.
- 편집기 격리 Awake/OnDestroy는 기본 복원·외부 두 값 변경·각 한 값 변경 네 경우와 품질 단계 변경 뒤 vSync 0/2 두 경우, 반복 해제/미초기화 제거를 확인한다. 엔진 검사에서는 실제 앱 컴포넌트 제거 후 같은 품질 단계의 캡처된 값 복원을 확인한다. 검사 자체는 개인 값과 검사 전 두 품질 단계/전역 설정을 보존한다.

## 2026-10-11 시작 없는 터치 신호

- 현재 Legacy EventSystem은 처음 본 손가락을 실제 `Began` 없이 `Ended`/`Stationary`/`Moved`로 받아도 누름 이벤트를 만들 수 있다. 명령과 레인은 현재 입력 모듈의 동일 손가락이 실제 `Began`인지 확인한 뒤에만 클릭 대기/레인 판정을 등록한다. 누르지 않은 해제로 재개하거나 점수/피해를 만들지 않는다.
- 무시한 손가락을 뗀 뒤 같은 ID로 새 터치를 시작하면 정상 입력으로 처리한다. 마우스·키보드·기존 시간 보호·판정 폭·저장/사용권·개인 데이터는 유지한다. 새 입력 시스템으로 전환한 것이 아니며 다른 입력 모듈이나 실제 휴대폰 OS 복귀를 검증했다고 표시하지 않는다.
- 격리 엔진 검사는 이미 보이는 활성 재개 버튼과 실제 레인에 종료/유지/이동을 첫 신호로 보내고 기본/상세 각각 세 경우의 무실행/무판정과 새 시작 복구를 비교한다. 실제 중단 콜백이 아닌 입력 시작 유실 경계의 합성 재현이다.

## 2026-10-11 전환 프레임의 새 명령 입력

- 기존 누름의 취소가 실제 입력 모듈의 새 누름 판정보다 먼저 일어날 수 있다. 새 화면이 아직 표시되지 않은 그 프레임에 시작된 명령 누름도 클릭 자격을 얻지 않는다. 오래 누른 뒤 떼어도 새 메뉴의 재개/로비 이동으로 이어지지 않는다.
- 취소 프레임만 막고 다음 프레임의 새로운 누름은 정상 처리한다. 반복 정지 갱신에 차단을 추가하거나 시간 보호·재개 여유·레인 판정·저장 형식/사용권을 바꾸지 않는다. 플레이하지 않는 격리 콜백 검사는 기존 동작을 유지한다.
- 편집기 입력 대역의 한 번짜리 읽기 콜백으로 실제 EventSystem의 입력 읽기와 새 화면 레이캐스트 사이를 재현한다. 터치/마우스 × 기본/상세 네 재개 경우의 이전 주행 영역·새 메뉴 적중·늦은 해제/수치 보존·새 입력 복구를 검사한다. 기본 표시의 로비 버튼은 전환 순간 아직 숨겨져 레인을 적중하므로 새 명령 재현 범위에 포함하지 않는다. 휴대폰 OS/손 입력이나 실제 프레임 성능 검사와 구분하며 입력 대역은 플레이어 빌드에 포함하지 않는다.

## 2026-10-10 확인 취소·확정 뒤 남은 입력

- 저장/무한 관리의 삭제·이름 확인을 취소할 때 기존 명령 누름을 취소한다. 취소 전에 누르고 있던 손을 늦게 떼는 것만으로 같은 확인창이 다시 열리지 않는다. 저장 포기 확인에서 상세로 돌아갈 때도 같은 기준이다.
- 이름 변경·삭제를 실제 확정하기 직전에 기존 명령 누름을 취소한다. 요청한 변경만 한 번 적용하고 남은 손이 새 확인/로비 이동으로 이어지지 않는다. 확인이 끝난 뒤 새로 누른 명령은 기존 규칙대로 동작한다.
- 보호 시간·슬롯 수/사용권·후보의 한 번 저장·확인 문구·데이터 형식은 바꾸지 않는다. 삭제는 고른 슬롯만 비우며 다른 슬롯과 저장 후보를 버리지 않는다. 이름 변경은 사용권을 소모하지 않는다.
- 격리 콜백 검사는 네 삭제/이름 취소·두 이름 확정·두 삭제 확정·저장 포기 취소 아홉 경우의 실제 활성 명령 등록과 취소, 후보/기록/사용권/이름 및 새 입력 복구를 확인한다. 실제 EventSystem 프레임과 전체 게임 루프는 별도 보고서로 검증한다. 개인 조합/포인트를 검사에 사용하지 않는다.

## 2026-10-10 기본 주행 수치 문구 재사용

- 기본 주행의 점수·거리·콤보/정확·Good·Miss 두 줄은 원래 표시 형식과 소수점/숫자 구분을 유지한다. 점수와 판정 수가 같으면 해당 조각을 재사용하고, 표시되는 거리까지 같으면 전체 문구를 재사용한다. 실제 거리·주행 속도·판정·보상은 바꾸지 않는다.
- 읽기 전용 문화권이 바뀌면 문구를 새로 만든다. 같은 객체의 숫자 형식도 바뀔 수 있는 수정 가능 문화권은 원래 생성기를 사용한다. 숫자 형식을 따로 고정하거나 사용자 설정을 변경하지 않는다.
- 실제 코어의 세 문화권·정확/Good/Miss·정지/재개·F11·무한 종료/새 연습·점수 상한과 같은 객체의 숫자 형식 변경을 원래 문구와 대조한다. 동일 문구 재사용은 최신 수치 누락과 구분한다.
- 격리 측정은 메모리 할당 이벤트 수만 비교한다. 같은 1,800단계에서 코어/판정 수는 유지하고 코어+렌더+UI 갱신은 79,377→68,071 이벤트, 동결 문구 500회는 4,000→0 이벤트다. CPU 개선·할당 바이트 크기·실제 프레임/FPS·휴대폰 성능을 측정한 것으로 표시하지 않는다.

## 2026-10-10 유지 입력 검사의 실제 대상

- 회전 입력 판정 직후에는 통로 레일 / 바닥 세그먼트 / 방향 바늘도 짧게 같은 방향으로 잔여 기울임을 남기고 Success / Good / Miss 색을 얇게 섞어, 폰을 돌려 통로를 맞췄다는 느낌을 주되 새 회전 통로가 오면 현재 입력 방향을 우선한다
- 회전 통로에서는 전방 속도선도 화면 전체를 돌리지 않고 같은 방향으로 아주 작게 드리프트 / 사선 편향을 받아, 템플런식 직선 주행은 유지하면서 놈식 회전 통로 감각만 짧게 들어오게 한다
- 회전 통로에서는 가까운 배경 기둥도 좌 / 우 정렬 방향으로 아주 작게 밀리고 기울어, 통로를 맞추는 공간감은 생기지만 제목 / HUD / 판정선 / 버튼은 고정된다
- 회전 통로에서는 주자 실루엣이 판정선 가까이에서만 아주 작게 같은 방향으로 무게중심을 옮기고 그림자도 따라가, 화면 전체 회전 없이 휴대폰을 살짝 돌려 버티는 느낌을 준다
- 회전 통로의 라이브 코치 / 목표 / 판정 피드백은 일반 `회피`가 아니라 `정렬`로 표시해 점프·숙이기·비틀기 함정과 기울임 통로를 분리해 읽게 한다
- 회전 통로의 중앙 액션 큐는 짧은 기록 표기와 달리 `↺ 좌회전 정렬`, `↻ 우회전 정렬`처럼 방향을 풀어 보여줘 모바일 기울임 입력과 화면 레일 기울기가 같은 의미로 읽히게 한다
- 회전 통로의 Miss / 입력 없음 도움말도 일반 좌우 탭 안내가 아니라 `정답 좌 기울임`, `정답 우 기울임`으로 유지한다
- 바닥 박자 타일은 활성 함정의 판정창이 가까워질수록 판정선 근처에서 더 넓고 납작하고 밝게 눌려, 소리 없이도 지금 눌러야 하는 접지 박자를 읽게 한다
- 터널 깊이감은 활성 함정이 판정선에 가까워질수록 살짝 압축되고 밝아지며, 무한모드 고위협에서는 더 강하게 조여와 정확 입력 직전의 공간 압박을 배경에서도 읽게 한다
- 직선 통로 레일 / 고리 / 중앙 이음선 / 페이스 마커는 활성 함정이 정확권에 가까울수록 낮은 폭·두께·알파 스퀴즈를 공유해, 새 장식을 늘리지 않고도 길 자체가 판정선 쪽으로 조여오는 느낌을 만든다
- 타이밍 눈금은 정확권에서 가장 가까운 눈금이 더 밝고 세로로 또렷하게 lock되고, 뒤쪽 눈금은 약하게 따라와 다음 박자와 실제 입력점을 구분하게 한다
- 목표 레인 glow는 정답 레인에만 켜지고 정확권에 가까워질수록 더 밝고 또렷하게 lock되어, 중앙 액션 큐를 놓쳐도 지금 눌러야 할 칸을 읽게 한다
- 목표 레인 glow도 다운비트 순간에 짧게 금색과 세로 스케일을 받아, 4박 첫 박과 실제로 누를 레인이 같은 순간에 묶여 보이게 한다
- 목표 레인 라벨도 같은 다운비트 순간에 짧게 금색과 세로 스케일을 받아, `좌 / 중 / 우` 글자만 봐도 첫 박과 눌러야 할 칸이 같이 읽히게 한다
- 목표 레인 라벨은 정확권에서만 살짝 세로로 또렷해져, `좌 / 중 / 우` 글자 자체도 지금 누를 칸을 가리키게 한다
- 함정 마커도 다운비트 순간에 짧게 금색과 형태별 스케일을 받아, 점프는 바닥을 더 넓게, 숙이기는 위협을 더 세로로, 비틀기는 측면 각도를 더 또렷하게 읽게 한다
- 함정 안의 `↑ / ↓ / ↔` 동작 기호도 다운비트 순간에 짧게 밝아지고 커져, 위험 모양과 실제 입력 동작이 첫 박에서 같이 읽힌다
- 함정 주변 글로우와 타격선도 같은 다운비트 리프트를 공유하되 위험 밴드는 알파만 살짝 올려, 첫 박 신호가 위험 표현을 보상 이펙트처럼 바꾸지 않게 한다
- 성공권 밴드는 정확 타이밍에 들어왔을 때만 별도 lock으로 더 밝고 세로로 또렷해져, Good권과 정확권의 차이를 판정창 자체에서도 읽게 한다
- 판정 밴드는 다운비트 순간에 짧게 같이 뛰되, 정확권 밴드가 Good권보다 더 강하게 반응해 첫 박과 입력 성공 창을 같은 기준으로 묶는다
- 중앙 정확선은 성공권 lock과 같은 정확권에서 더 밝고 세로로 또렷해져, 목표 레인 / 성공권 / 마커 기호가 같은 순간을 가리키게 한다
- 판정선 자체도 정확권 lock에서 색과 세로 선명도가 아주 작게 더 올라가, 함정이 판정선에 닿는 순간과 입력 순간이 같은 선 위에 찍히게 한다
- 하단 타이밍 가이드 문구도 같은 정확권 lock에서 색과 알파, 세로 스케일이 살짝 올라가 `지금 누르는 순간`을 텍스트 움직임으로도 확인하게 한다
- 함정 마커는 판정선에 가까워질수록 바닥 위험은 더 낮고 넓게, 상단 위험은 더 세로로 눌리듯 크게, 측면 위험은 더 길고 기울어지게 반응해 회피 동작의 차이를 마커 실루엣에서도 읽게 한다
- 마커 안쪽 `↑` / `↓` / `↔` 기호는 정확권에서 더 밝고 크게 lock되어, 모양과 기호가 같은 회피 행동을 동시에 가리키게 한다
- 주자 그림자와 몸 스케일은 보폭이 땅에 닿는 순간과 정확 타이밍 근처에서 살짝 넓어지고 눌려, 리듬 입력이 발밑 접지감으로도 이어지게 한다
- 주자 발밑 접지 피프는 왼발/오른발이 보폭에 맞춰 번갈아 낮게 켜지고, 정확권 다운비트와 접지 강도에서만 조금 더 밝아져 리듬 주행감을 숫자 없이 보강한다
- 주자 실루엣도 활성 함정이 가까운 다운비트에서만 아주 짧게 준비 자세를 강조해, 점프는 위로 튀려는 느낌, 숙이기는 낮고 넓어지는 느낌, 비틀기는 좁아지고 기우는 느낌을 첫 박에 같이 읽게 한다
- 주자 파츠의 뿔 / 짙은 머리 / 주홍 허리띠는 판정색에 묻히지 않도록 매 프레임 기준 위치로 되돌린 뒤 동작별로만 작게 변형한다. 점프는 머리와 뿔이 들리고, 숙이기는 머리와 허리띠가 낮고 넓어지며, 회전 통로는 허리띠와 머리 오프셋이 좌우 방향을 짧게 가리킨다
- Good 판정과 타이밍 Miss는 코치 줄에도 `빠름 Nms→살짝 늦게`, `늦음 Nms→살짝 빠르게`를 남겨 `보정`이 단순 생존이 아니라 다음 입력을 살짝 늦게 / 빠르게 조정하는 신호가 되게 한다
- Good / 타이밍 Miss / 채널 오류 / 입력 없음 직후에는 상단 목표 줄에도 `다음은 살짝 빠르게`, `다음은 조금 늦게`, `정답 채널 확인`, `다음 함정 입력` 같은 짧은 수정 목표를 이어 붙여 코치 줄을 놓쳐도 다음 입력 기준을 잃지 않게 한다
- 체력 1칸의 `생존 우선` 목표는 현재 함정의 `바닥→↑점프 회피` 같은 회피 동작과 Good / Miss 직후 타이밍 수정 목표를 덮어쓰지 않고 같이 보여줘, 위험 상태에서도 무엇을 눌러 살아야 하는지와 다음 입력 기준이 사라지지 않게 한다
- 콤보 3 이상부터 Success 시 `연쇄 박자` 보너스 점수와 HUD 연쇄 배율 표시
- Good / Miss로 연쇄가 끊기면 판정 문구에 `연쇄 끊김` 표시
- 생존 가능한 Miss 뒤에는 판정 여유가 있는 복구 함정을 1회 배치
- 복구 함정 중앙 정박은 `복구 정박`으로 판정해 점수 +75, 집중 +1, 콤보 +1 추가 보상
- 복구 함정 Good은 생존 흐름만 유지하고 중앙 정박 추가 보상은 주지 않음
- Perfect 함정 중앙 정박은 `정박 충전`으로 판정해 집중 +1 추가 보상
- Clutch 함정 중앙 정박은 `압박 반격`으로 판정해 점수 +50 추가 보상
- Offbeat 함정 중앙 정박은 `엇박 연쇄`로 판정해 콤보 +1 추가 보상
- 복구 정박 / 압박 반격 / 엇박 연쇄 횟수를 런 기록과 결과 흐름에 보존
- 프로필 장식 화면에 정박 충전 / 압박 반격 / 엇박 연쇄 최고 숙련과 배지 진행을 표시
- 안정 루트는 넓은 판정에 더해 Good 성공 시 손실 체력을 1 회복해 실수 복구 역할을 분명히 한다
- 변주 루트는 엇박 함정을 우선 배치하고 중앙 정박 시 집중을 1 추가해 엇박 운용 보상을 준다
- 압박 루트는 Clutch 함정을 우선 배치하고 중앙 정박 반격 점수에 35점을 추가해 좁은 판정의 고점을 보상한다
- 안정 복구 / 변주 공명 / 압박 증폭 횟수는 런 기록과 결과 흐름에 보존한다
- 경로 선택지, 활성 코치, 런 목표, 중앙 판정 피드백은 같은 경로 보상 규칙을 안내한다
- 안정 복구는 초록 회복 피드백, 변주 공명은 보라색 집중 피드백, 압박 증폭은 주황색 고점 피드백으로 구분한다
- 경로 보상 발동음과 진동 강도도 회복 / 변주 / 압박 성격에 맞춰 분리한다
- 경로 보상 진동은 안정 복구 < 변주 공명 < 압박 증폭 순서로 강해지며, 목표 달성 순간에는 한 단계 더 강한 펄스로 검증한다
- 저장 조합의 지배 경로를 무한모드에 복원하면 같은 안정 / 변주 / 압박 지속 보상이 유지된다
- 현재 경로는 런 스냅샷의 정식 상태로 유지하고 챕터 제목과 하단 상태 안내에 계속 표시한다
- 각 경로의 첫 함정은 안정 Perfect / 변주 Offbeat / 압박 Clutch 성격을 우선 제시해 선택 결과를 즉시 체감하게 한다
- 경로 선택 칸과 첫 함정 예고는 Good 회복 +1 / 엇박 집중 +1 / Clutch 점수 +35 수치를 동일하게 표시한다
- 일반 런과 무한모드 종료 HUD에 실제 발동한 안정 / 변주 / 압박 경로 보상 횟수를 한 줄로 정산한다
- 결과 강점 분석은 선택한 경로 이름만 보지 않고 안정 복구 / 변주 공명 / 압박 증폭 실제 발동 횟수를 우선한다
- 에디터 / 개발 빌드 오른쪽 도구에 `경로 안정 ↑↓↔ → 경로 변주 ↔↓↑ → 경로 압박 ↓↔↑` 순환 체험 버튼과 F8 단축키를 제공한다
- 경로 체험은 2장 대표 함정 직전으로 이동하고 점수 / 판정 / 거리 기준을 초기화해 세 경로를 같은 조건에서 비교하게 한다
- 경로 체험 대표 함정은 안정 Perfect / 변주 Offbeat / 압박 Clutch로 시작하며 본게임 빌드에는 노출하지 않는다
- 프로필 장식 화면에 안정 복구 / 변주 공명 / 압박 증폭 최고 기록과 3회 달성 배지를 표시한다
- 타이밍 축 숙련 뒤에는 세 경로 보상 3회 달성을 다음 흔적 목표로 순서대로 안내한다
- 경로 추천은 첫 구간 실수 / 보정이면 안정, 첫 구간 완전 정확이면 압박을 유지한다
- 안정 경로에서 다음 구간을 정확하게 돌파하면 변주를 `안정 졸업` 단계로 추천한다
- 변주 경로까지 완전 정확으로 돌파하면 압박 고점 경로를 다음 단계로 추천한다
- 2~3장의 기본 3함정 배열은 안정 `Perfect-Clutch-Perfect`, 변주 `Offbeat-Perfect-Offbeat`, 압박 `Clutch-Offbeat-Clutch`로 구분한다
- 3장 가운데 함정은 선택 유물의 Perfect / Offbeat / Clutch 성격을 우선해 경로 리듬에 유물 변화를 섞는다
- 같은 경로의 3함정을 모두 정확으로 통과하면 경로 전용 완주 보상을 지급한다
- 안정 완주는 체력 +1, 변주 완주는 집중 +2 또는 집중 상태 연장, 압박 완주는 점수 +150과 집중 흐름을 지급한다
- 진행 HUD는 `안정/변주/압박 완주 N/3`을 표시하고 마지막 함정 목표에 받을 완주 보상을 미리 표시한다
- 완주 순간의 화면 플래시 / 합성음 / 진동 / 전환 라벨은 안정 초록, 변주 보라, 압박 주황으로 구분한다
- 안정 완주 / 변주 완주 / 압박 완주 횟수는 런 기록, 종료 정산, 결과 강점, 프로필 경로 완주에 보존한다
- 경로 3함정 중 Good 또는 Miss가 처음 발생하면 `안정/변주/압박 완주 중단`을 즉시 표시하고, 남은 구간 HUD에도 중단 상태를 유지한다
- 안정 경로의 Good 체력 회복 같은 개별 보상은 완주 중단 뒤에도 정상 지급하되 3함정 정확 완주 보상과 분리한다
- 노드 선택 화면은 안정 `정-압-정`, 변주 `엇-정-엇`, 압박 `압-엇-압` 박자 지도를 한 줄로 비교한다
- 2~3장 중앙 설명은 현재 경로의 3박 배열을 표시하고 진행 중인 박자만 `[정]`, `[압]`, `[엇]`으로 강조한다
- 3장에서는 선택 유물이 바꾼 가운데 박자를 경로 지도에도 즉시 반영하고 `유물 변주`로 이름을 붙인다
- 구간 판정 기반 경로 추천 이유에는 추천 경로의 3박 배열을 함께 표시해 다음 연습 내용을 바로 알 수 있게 한다
- 경로 함정 1·2번째 판정 직후 중앙 피드백과 코치에 현재 `N/3`, 다음 박자, 마지막 완주 보상을 이어서 표시한다
- Good 또는 Miss 뒤에는 다음 박자를 `연습`으로 안내해 남은 함정은 계속 읽되 이번 구간 완주 보상은 끊겼음을 구분한다
- 4장 공명핵 구간과 탈출 검증도 고정 `압-엇-정` 배열의 현재 박자, 다음 박자, 경로 완주 보상을 같은 방식으로 안내한다
- 상단 진행 바 안에는 3칸 경로 박자 표시를 두고 완료 / 현재 / 대기 / 완주 중단 상태를 색과 크기로 구분하되, 현재 칸은 판정 창에 가까워질수록 더 밝고 크게 박자 펄스를 낸다. 선택 / 일시정지 / 카운트다운 / 결과 화면에서는 숨겨 메뉴와 정산 문구를 덮지 않는다
- 전진선 속도와 선 길이는 정확 입력 보상에서 가장 크게, Good 보상에서 약하게 상승하고 Miss 비틀거림 회복 중에는 감속과 붉은 회복 압박 틴트를 함께 적용해 `피했다`와 `걸렸다`의 체감 차이를 화면 속도와 색에서 먼저 읽게 한다. 회전 통로에서는 같은 전진선이 좌/우 기울임 방향으로만 미세하게 쏠려, 화면 전체 회전 없이 통로 정렬 압박을 보강한다
- 챕터 3은 기프트·유물·연속 대응이 가장 강하게 살아나는 `변주 정점`으로 표시한다
- 챕터 4와 탈출은 새 규칙을 추가하는 구간이 아니라 기존 `압-엇-정`을 끝까지 증명하는 `공명핵/탈출 검증`으로 표시한다
- 최종 검증 구간은 챕터 3보다 빨라지지 않도록 기본 템포 시간을 4% 늘리고 판정 폭을 5% 넓혀 혼합 읽기에 집중시킨다
- 상단 진행 바는 챕터 1 `학습`, 챕터 2 `방향 형성`, 챕터 3 `변주 정점`, 챕터 4 `공명핵 검증`, 마지막 `탈출 검증` 역할을 함께 표시한다
- 챕터 마지막 함정의 정밀 보상 문구는 선택 화면 전환 뒤에도 중앙 피드백에 유지
- 입력 판정 보정값을 ±200ms 범위에서 20ms 단위로 조정
- 보정값은 PlayerPrefs에 저장해 에디터 재시작 뒤에도 유지
- 오른쪽 테스트 패널에서 빠름 +20 / 보정 0 / 늦음 -20 버튼 제공
- 판정 계산에는 보정값을 반영하고, 시각 마커와 판정선은 원래 박자 기준 유지
- HUD에 현재 입력 보정값 표시
- 런 HUD는 상태 / 보상 / 코칭 줄이 6줄 이상으로 길어지면 폰트와 박스 높이를 낮춰 중앙 판정선과 액션 큐를 침범하지 않게 한다
- 런 HUD는 활성 함정이 정확권에 가까운 다운비트일 때만 글자 색과 스케일이 아주 작게 살아나, 문구를 늘리지 않고도 현재 박자 기준을 읽게 한다. 저체력 / 무한 고위협에서는 같은 반응을 조금 더 읽기 쉽게 올리고, 일시정지 / 선택 / 카운트다운 / 결과 화면에서는 이 숨쉬기 반응을 끈다
- 상단 진행 문구도 활성 함정이 정확권에 가까운 다운비트에서만 살짝 밝아지고 커지며, 구간 전환 펄스와 함께 현재 구간 / 위협 / 탈출 진행이 같은 박자 기준을 공유하게 한다
- 로비 알림, 저장 / 무한 관리 상세, 기록 보드, 흔적 보드, 성장 보드는 줄 수가 늘어나면 폰트와 본문 높이를 단계적으로 낮추거나 키워 모바일 화면에서 핵심 기록값과 다음 행동이 겹치지 않게 한다
- 채널 오류는 입력 채널과 정답 채널을 함께 표시
- 기초연습은 `Perfect → Clutch → Offbeat` 세 축을 고정 순서로 생성해 안내 문구와 실제 함정이 항상 일치하게 한다
- 기초연습 제목·목표·진행 바는 `정박 바닥→↑점프`, `클러치 상단→↓숙이기`, `엇박 측면→↔비틀기`와 각 목표 줄로 현재 위험군, 동작, 타이밍 축을 각각 표시한다
- 기초연습 상단 진행 바도 3칸 타이밍 색을 사용하고 지나간 단계 / 현재 단계 / 대기 단계를 구분한다
- 기초연습 완료는 실수 포함 시 `실수 구간 다시`, Good만 포함 시 `정확권 다시`, 전부 정확 시 `3축 다시 확인`으로 재시작 행동을 구분한다
- 기초연습 시작 안내도 `바닥→↑점프 정확→집중`, `상단→↓숙이기 정확→반격`, `측면→↔비틀기 정확→연쇄`를 먼저 보여줘 연습이 단순 조작 확인이 아니라 정확 타이밍 보상 학습으로 읽히게 한다
- 기초연습 판정은 일반 런 챕터 기록과 저장 후보를 만들지 않으며, 전부 정확해도 일반 런용 묶음 보상은 지급하지 않는다
- 기초연습의 유효 타이밍 샘플이 3회 모이면 완료 화면에 현재 보정 안정 또는 추천 입력 보정 값을 표시한다
- 기초연습 종료 상태에서는 수동 ±20ms 버튼은 잠그고, 실제 차이가 있는 가운데 `추천 적용` 버튼만 사용할 수 있게 한다
- 집중이 최대치일 때 Miss가 나면 체력 피해 대신 집중을 전부 소모해 1회 보호
- HUD에 집중 보호 준비 / 충전 상태 표시
- 집중이 1칸 남은 준비 상태에서는 주자 코어 glow가 켜지고 활성 함정의 4박 첫 박 다운비트에 짧게 더 밝아져, 다음 정박 충전이 집중 상태로 이어질 수 있음을 텍스트 없이도 읽게 한다
- 오른쪽 테스트 패널에서 `집중 발동` / `집중 리필` 버튼으로 집중 보호 검증 상태를 즉시 만들 수 있음
- 자동 시작 / 정지 흐름
- 함정 종료 후 러닝 복귀 간격을 둔 자동 다음 패턴 생성
- 진행 거리 표시
- 체력 0 시 탈출 실패 상태 표시
- 체력 0 이후 자동 버튼을 다시 시작으로 전환

## 6-3 구현 범위

- 일반 런 한 판의 최소 구조 추가
- 시작 기프트 선택
- 새 프로필의 기초연습은 정확 3축 완료 시 강조 버튼이 `일반 런으로` 바뀌며 로비를 다시 거치지 않고 첫 일반 런의 `시작 기프트 선택`으로 이어진다. Good/Miss가 남으면 보정/실수 복기를 우선하고, 연습을 나갈 때만 온보딩 완료를 확정한다.
- 챕터 1~3 진행
- 챕터별 노드 선택
- 챕터별 기프트 선택
- 챕터 2 중반 유물 선택
- 챕터 4 공명핵 회수
- 공명핵 회수 뒤 탈출 검증 진행
- 탈출 성공 시 저장 가능한 상태 표시
- 체력 0 시 탈출 실패 상태 유지
- 선택지 선택 시 체력 / 집중 / 콤보 / 점수 보상 즉시 반영
- 선택 입력이 확정되면 직전 좌 / 중 / 우 후보와 판정 문구를 비교해 선택 레인을 복원하고, 해당 레인에 약 0.56초의 성향색 파동과 레인별 음높이·확정음·짧은 진동을 한 번만 남긴다. 노드에서 기프트처럼 다음 선택으로 이어질 때는 가볍게, 최종 선택에서 시작 카운트다운으로 넘어갈 때는 한 단계 단단하게 재생한다. 최종 확정 약 0.14초 뒤 챕터 전환음을 열고 약 0.38초 뒤 첫 카운트 클릭을 시작해 `선택 확정 → 챕터 진입 → 2-1-GO`가 겹치지 않게 하며, 반복 카운트다운 스냅샷에서는 다시 재생하지 않는다
- 챕터 전환 배너의 키·타이머·전환음은 선택 화면에서 미리 소비하지 않는다. 최종 선택이 끝난 시작 카운트다운부터 새 챕터 배너를 예약해 플레이어가 선택을 오래 고민해도 `CHAPTER N` 안내가 사라지지 않게 한다. 예약음이 아직 시작되기 전에 일시정지 / 다른 선택으로 바뀌면 오래된 예약은 취소하되 챕터 키를 다시 열어 재개 뒤 한 번 새로 안내한다. 이미 전환음이 난 배너, 결과 화면으로 끝났거나 타이머가 만료된 배너는 다시 재생하지 않는다
- 챕터 전환 배너가 중앙에 나타나는 동안 같은 자리를 쓰는 런 설명문은 배너 가시도에 맞춰 거의 숨기고, 배너가 끝나면 완전히 복원해 카운트 설명과 `CHAPTER N` 문구가 겹치지 않게 한다
- 선택 중에는 자동 진행 버튼을 선택 대기로 전환
- 선택지 문구가 좌 / 중 / 우 입력 칸 안에 들어가도록 폰트 자동 조정
- 탈출 성공 후 마지막 버튼을 입구로 나가기로 전환하고, 진행 바 라벨은 `탈출 게이트 3/3 완료 · 입구로 나가기`로 게이트 완료와 다음 행동을 연결한다
- 입구로 나가기 선택 시 런 종료 후 로비 복귀
- 진행 중 로비 복귀 버튼은 탈출 포기로 표시
- 테스트용 오른쪽 바로가기 패널 추가
- 오른쪽 테스트 패널과 키보드 단축키는 에디터 또는 디버그 빌드에서만 켜지는 `GreedLastDevToolPolicy`를 통해 노출하고, 일반 릴리스 빌드에서는 숨긴다
- 테스트 무적 ON / OFF
- 일반 런 테스트에서는 `PgDn 피해 -1`로 체력을 1까지 낮춰 체력 위험 비네트를 바로 확인하고, F10 낙하 보기로 함정 접근 속도 프리뷰를 보통/느림/빠름으로 확인한다. 무한모드에서는 기존 `PgDn 위협 -1`로 위협 단계를 내린다
- 기프트 선택 구간 바로가기
- 유물 선택 구간 바로가기
- 공명핵 회수 직후 바로가기
- 탈출 직전 바로가기
- 공명핵 회수 후 탈출 구간도 자동 진행 대상에 포함
- 로비 중앙 안내 문구 숨김
- 탈출 성공 후 입구로 나가면 첫 저장 완료 처리
- 탈출 성공 후 `입구로 나가기`를 누르면 `저장 슬롯 선택` 화면으로 들어가고, 본문 첫 줄은 `클리어 요약`으로 시작해 기록 한 줄 / 판정 / 저장 후보 / `저장 기회: 1회`를 먼저 보여준다
- 첫 저장이 없는 상태에서는 저장 조합 버튼으로 후보를 저장하거나 포기하라는 문구 표시
- 기존 저장 슬롯이 있으면 저장 조합에서 후보 비교 뒤 저장하거나 포기할 수 있다는 문구 표시
- 저장 후보는 1회성이다. 저장 확정이나 포기 뒤에는 같은 클리어 후보로 다시 저장할 수 없고, 다시 저장을 누르면 새 저장은 다음 클리어 후 1회만 가능하다는 후보 없음 안내로 빠진다
- 로비 기본 동기화 문구는 숨기되, 클리어 / 저장 완료 / 무한 기록 같은 실제 안내는 중앙에 표시
- 저장 후보 대기와 저장 조합 없음 같은 행동 안내는 기본 동기화 문구와 다르게 중앙 안내로 유지하고, 스모크에서 숨김 여부를 검증한다

- `Esc` 일시정지 메뉴는 배경을 어둡게 눌러 주변을 흐릿하게 느끼게 하고, 중앙에 별도 패널 오버레이로 표시하며, 블러 배경이 아래 레인 / 버튼 터치를 차단한다

- 일시정지 중 앱 레벨 좌 / 우 입력은 런 코어로 내려보내지 않고, 중앙 입력만 재개 카운트 진입으로 사용한다

- 런 화면에 체력 / 집중 게이지를 추가해 체력 0 위험과 집중 MAX 상태를 텍스트 HUD 없이도 즉시 볼 수 있게 함

- 런 화면 중앙 상단에 콤보 / 연쇄 배지를 추가해 Success가 이어질 때 리듬 보상감을 별도 UI로 확인할 수 있게 함

- 정확 입력 직후 판정 피드백은 같은 보상 목적을 `정확→집중`, `정확→반격`, `정확→연쇄`, `정확→회복`, `정확→고점`처럼 반복해, 입력 전 상태줄의 목적과 입력 후 보상이 끊기지 않게 한다

- 플레이 중 코치 라인은 `정확→...` 보상 목적을 먼저 말한 뒤 위험 회피, 박자, 경로 보상을 이어 붙여 그래픽 전 단계에서도 지금 눌러야 하는 이유가 사라지지 않게 한다

- 런 중 목표 줄도 활성 함정이 있으면 `바닥→↑점프 회피 / 정박 중앙 집중 +N`처럼 필요한 위험군, 회피 동작, 리듬 보상을 함께 표시한다
- 런 중 코칭 줄은 활성 함정의 위험군과 회피 동작을 `바닥→↑점프 회피`, `상단→↓숙이기 회피`, `측면→↔비틀기 회피`처럼 먼저 표시한 뒤 타이밍 축과 보상을 붙여 피하기와 리듬 입력을 한 줄에서 읽게 한다
- 활성 함정이 내려오는 동안 목표 레인은 `바닥→↑점프 · 충전+1`처럼 위험군 / 회피 동작 / 정확 보상을 함께 보여주고, 판정선 근처에는 `바닥 위험 → ↑ 점프 회피 · A/← · 1박 전 · 정확+...→집중` 같은 별도 액션 큐를 띄워 레인 텍스트를 읽지 않아도 지금 피할 위험군, 동작, 에디터 입력 키, 정확 입력 보상 목적을 확인하게 한다

- 정확 성공은 짧은 금색 통과 궤적, Good은 더 약한 보정 궤적, Miss는 붉은 충격 잔상으로 갈라 판정 품질을 텍스트 없이도 비교하게 한다

- 약점 단계 복기 연습에서 `다시 연습`을 누르면 같은 복기 문맥과 시작 단계를 유지해 반복 확인할 수 있다
- 실패/중단 직후 흔적의 `다음 행동`은 성장 보정보다 약점 단계 복기 연습을 먼저 안내한다
- 무한모드 종료 직후 흔적의 `다음 행동`도 무한 재도전 전에 약한 회피 동작의 기초연습 단계를 확인하도록 안내한다
- 기초연습 완료 화면은 실패 또는 보정된 위험군 / 회피 동작과 단계 번호를 직접 지목하고, 전부 정확하면 `바닥→↑점프 · 상단→↓숙이기 · 측면→↔비틀기 정확` 완료를 표시한다
- 1장과 기초연습은 점프-숙이기-비틀기 순서로 세 회피 동작을 모두 소개한다
- 안정 경로는 점프-숙이기-비틀기, 변주 경로는 비틀기-숙이기-점프, 압박 경로는 숙이기-비틀기-점프 동작 배열을 우선한다
- 4장 공명핵과 탈출 검증은 숙이기-비틀기-점프 혼합 배열로 마무리하며, 동작 패턴이 타이밍 배열과 충돌하면 기존 박자 규칙을 우선한다
- 노드 선택 화면은 박자 지도 아래에 안정 `점-숙-틀`, 변주 `틀-숙-점`, 압박 `숙-틀-점` 동작 지도를 함께 비교한다
- 루트 선택 버튼 힌트도 안정 `정-압-정 / 점-숙-틀`, 변주 `엇-정-엇 / 틀-숙-점`, 압박 `압-엇-압 / 숙-틀-점`을 직접 표시해 버튼만 봐도 다음 박자와 회피 배열을 고를 수 있게 한다
- 루트 선택 버튼 내부는 `보상 수치`와 `박자 / 동작 지도`를 줄바꿈으로 나눠 좁은 모바일 버튼에서도 긴 힌트가 한 줄로 밀리지 않게 한다
- 노드 선택 상단 미리보기는 보상 수치를 반복하지 않고 좌/중/우의 루트 이름과 박자/동작 지도만 압축해 세 선택지를 한 줄로 비교한다
- 런 중 박자 지도는 현재 동작을 대괄호로 강조하고, 판정 직후 코치는 다음 타이밍과 점프 / 숙이기 / 비틀기를 함께 예고한다
- 중앙 액션 큐는 목표 레인이 좌 / 우일 때 해당 방향으로 작게 치우치고, 정박 펄스 때 한 번 더 살짝 밀려 텍스트를 다 읽기 전에도 어느 레인을 눌러야 하는지 방향감이 생기게 한다
- 중앙 액션 큐는 활성 함정이 성공 창에 가까워질수록 박자에 맞춰 조금 더 밝아지고 커지며, 정확 창 안에서는 한 번 더 숨을 쉬듯 커져 “지금 누를 문구”가 정적인 안내문이 아니라 리듬 신호처럼 읽히게 한다
- 중앙 액션 큐도 다운비트가 살아 있는 짧은 순간에 알파와 스케일을 조금 더 받아, 소리 / 바닥 / 터널 / 문구가 같은 4박 첫 박 기준으로 묶인다
- 하단 타이밍 가이드도 활성 함정이 가까운 다운비트에서만 작게 금색과 세로 스케일을 받아, 중앙 큐를 놓쳐도 첫 박 기준을 다시 읽게 한다
- 배경 이동 배율은 1장 학습에서 낮게 시작해 2장 방향 형성, 3장 변주 정점 순으로 커지고 4장 검증에서는 속도를 낮춘 채 깊이만 강조한다
- 탈출 검증은 일반 챕터보다 전진선과 기둥 이동을 강하게 해 공명핵을 들고 빠져나가는 속도감을 만들며 실제 함정 타이밍은 바꾸지 않는다
- 공명핵 회수 후 탈출 검증 중에는 진행 막대 아래 3칸 탈출 게이트 피프가 켜지고, 현재 열어야 할 칸은 판정 창에 가까워질수록 더 밝고 크게 박자 펄스를 낸다. 4박 첫 박 다운비트가 겹치면 현재 칸과 완료 직전 마지막 칸이 한 번 더 밝고 크게 살아나 탈출 끝점을 리듬으로 읽게 한다. HUD와 목표 줄도 `탈출 게이트 0/3` → `입구 직전 게이트 2/3`로 같은 진행을 말한다. 탈출 성공 요약에서는 `입구로 나가기`를 누르기 전까지 3칸 완료 상태를 유지한다
- 바닥 박자 타일, 기둥 이동, 주자 보폭은 판정선 아래쪽 흐름과 함께 전진선과 같은 성공 가속 / Miss 회복 감속 / 피격 회복 틴트 기준을 공유하고, 챕터 속도, 무한 위협, 집중 상태, 정확 보상 순간에 맞춰 밝아져 단색 프로토타입에서도 달리는 리듬을 읽게 한다
- 콤보 배지 하단의 정박 보상칸 3개는 정확 입력이 쌓일수록 1칸씩 켜지고, 3칸이 모두 찬 순간 집중 보상 직전/발동을 눈으로 읽게 하며 보상 준비 다운비트에서는 마지막 칸이 가장 강하게 살아난다. 선택/일시정지/카운트다운/결과 화면에서는 숨긴다
- 콤보 배지 배경/액센트/스케일과 성공 화면 플래시는 정박 보상 진행도와 연쇄 상승 펄스를 약하게 받아, 텍스트를 읽지 않아도 다음 보상 직전의 리듬 상승감을 확인하게 한다
- 화면 판정 플래시는 시작 직후 아주 짧게 원래 세기를 유지한 뒤 부드럽게 사라져, 정확 / Good / Miss / 묶음 완료 피드백이 갑자기 끊기는 느낌을 줄인다
- 체력 게이지 아래의 3칸 위험 피프는 체력이 절반 이하로 내려간 순간부터 차오르고 체력 1칸 / 무한 위협 고단계에서 박자와 4박 첫 박 다운비트에 맞춰 더 크게 뛰어, 붉은 화면 가장자리와 하단 `체력 위험` 안내 사이의 중간 신호 역할을 한다
- 레인 판정 태그, 레인 판정 펄스, Miss 흔들림, 판정 히스토리 잔상, 판정선 입력 흔적, 화면 판정 플래시, Miss 끊김 라인, 3동작 정확 burst는 라이브 런 피드백 상태에서만 유지되고 선택 / 일시정지 / 카운트다운 / 결과 화면으로 넘어가면 즉시 숨긴다
- 기록 보드 정리기는 `체력 위험`, `Good 이상 생존`, `위험 유지` 같은 생존 가이드와 테스트 버튼 문구를 점수 행에서 제거해 기록만 남긴다
- 기록 보드 정리기는 `빠름 Nms`, `늦음 Nms`, `다음은 살짝 ...`, `오입력`, `앞 박자 여유`, `카운트와 앞 박자 여유` 같은 일시 피드백도 제거해 복기/플레이 보정 문구가 랭킹처럼 보이지 않게 한다
- 기록 보드 정리기는 `정박 보상까지`, `연쇄 보너스`, `집중 1칸`, `집중 상태`, `회복 압박`, `압박 틴트` 같은 live 보상/연출 코치도 제거하고 실제 `콤N` 기록은 유지한다
- 집중 상태가 발동되면 집중 게이지 하단의 5칸 타이머가 남은 시간을 칸 단위로 줄여 보여주고, 마지막 1초대에는 타이머 칸이 다운비트에서 더 밝고 크게 뛰며 판정선 금색 밴드의 박자 펄스와 맞물려 집중 보호/배율 시간이 끝나가는 압박을 숫자 없이도 읽게 한다
- 런 배경과 전진선의 강조색은 챕터 기본색에 현재 조합 성향, 안정 / 변주 / 압박 루트, 유물, 집중 상태, 무한 위협 단계를 섞어 같은 판정판 안에서도 구간 성격을 읽게 한다
- 활성 함정이 판정선에 가까워지는 동안 배경과 강조색은 해당 회피 동작 / 타이밍 / 루트 성향 색을 살짝 받아, 중앙 문구를 읽지 않아도 지금 함정이 살아 있다는 분위기 압박을 만든다. 이 분위기 가중치는 선택 / 일시정지 / 카운트다운 / 결과 화면에서는 꺼진다
- 목표 레인 glow는 정답 레인에만 남고 판정선에 가까울수록 박자에 맞춰 조금 더 밝고 두꺼워지며, 판정 직후에는 레인 태그 색을 살짝 받아 눌렀던 레인 반응과 이어진다
- 한 묶음에서 점프·숙이기·비틀기를 각각 한 번 이상 모두 정확 판정하면 `3동작 정확` 구간으로 기록한다
- 런 중 상태 줄에는 현재 정확 묶음에서 채운 회피 동작과 다음에 비어 있는 동작을 `동작 ↑↓ 2/3→↔`처럼 짧게 표시하고, Good/Miss로 완주가 끊기면 `동작 완주 중단`으로 바꾼다
- `3동작 정확`은 루트 완주 전환 피드백, 결과의 회피 요약, 정산 HUD의 `3동작 N` 짧은 태그에 누적 구간 수로 표시한다
- `3동작 정확` 완주 순간에는 루트 배너 뒤에 성과명을 붙이고 완주음·진동·판정 이력 펄스를 일반 완주보다 한 단계 강하게 재생한다
- `3동작 정확` 완주 순간에는 판정선 근처에서 세 개의 작은 burst 칸이 퍼졌다 사라져 점프·숙이기·비틀기를 모두 정확히 넘긴 성과를 텍스트를 읽기 전에도 보여준다
- `3동작 정확`은 흔적 장식 페이지의 `동작 성과`와 획득 배지에 남겨 세 회피 동작을 모두 정확히 넘긴 기록을 장기 성과로 보존한다
- 에디터 / 개발 빌드의 `동작 확인` 버튼과 F9는 점프 정박 → 숙이기 클러치 → 비틀기 엇박 → 좌회전 통로 → 우회전 통로 대표 함정을 순환하고, 버튼 라벨과 카운트다운 안내는 `동작 ↑ 점프` / `다음 ↓ 숙이기` / `다음 ↺ 회전 Q` / `다음 ↻ 회전 E`, `Q / 좌 기울임`, `E / 우 기울임`처럼 다음 비교 대상과 에디터 회전키를 같이 표시한다
- 동작 확인 바로가기는 매번 점수·거리·판정 기준을 초기화해 세 궤적과 자세를 같은 조건에서 비교하며 릴리스 빌드에는 노출하지 않는다
- 위험 영역은 점프에서 낮고 넓은 바닥 띠, 숙이기에서 위에서 내려오는 상단 띠, 비틀기에서 가늘게 관통하는 측면 띠로 구분한다
- 함정 마커 실루엣도 점프는 낮고 넓은 바닥 쓸기, 숙이기는 두꺼운 상단 압박, 비틀기는 가늘고 기울어진 측면 공격으로 계산을 분리하고 스모크에서 고정한다
- 함정 마커 안에는 중앙 가이드와 같은 회피 기호 `↑`, `↓`, `↔`를 얹어 모양만으로 부족한 단색 프로토타입에서도 대응 동작을 즉시 읽게 한다
- 위험 영역의 형태는 타이밍 판정값을 바꾸지 않고 그래픽 교체 전에도 필요한 회피 동작을 공간적으로 읽게 하는 프로토타입 표현이다
- Good / 정확 판정 밴드는 활성 함정이 가까워질수록 조금 더 밝아지고, 정확 창은 목표 레인 안에서 살짝 넓어지며 정박 펄스 때 숨을 쉬듯 커져 성공 가능 구간을 숫자 없이도 읽게 한다
- 실패 충돌 잔상은 바닥의 넓은 충격, 상단의 압착, 측면의 기울어진 베임으로 나누고 동작별 진동 길이도 짧음·김·중간으로 구분한다
- 동작별 실패 표현은 판정 결과를 바꾸지 않으며 그래픽 제작 뒤 실제 함정 이펙트가 대체할 자리와 촉각 기준을 먼저 고정한다
- 성공 자세는 점프에서 위로 뜨고 그림자가 작아지며, 숙이기에서 낮고 넓어지고, 비틀기에서 좌우 이동과 회전이 생기도록 분리해 단색 프로토타입에서도 회피 실루엣을 비교할 수 있게 한다
- 활성 함정이 판정선에 가까워지면 입력 전부터 점프는 살짝 웅크리고, 숙이기는 낮고 넓어지며, 비틀기는 옆으로 몸을 빼는 예비 자세를 보여줘 `무엇을 눌러야 하는지`를 시각적으로 미리 읽게 한다
- 활성 함정의 예고 눈금은 같은 판정값을 유지한 채 함정의 실제 경로 위에 찍히며, 1박 전 쪽이 더 낮고 선명하고 크게 보여 입력 시점을 시각적으로 예습하게 한다
- 예고 눈금은 활성 박자에 가까울수록 박자 펄스로 약간 더 두껍고 밝아지며, 가장 가까운 눈금이 먼 눈금보다 더 크게 반응해 소리 없이도 `한 박 전` 위치를 읽게 한다
- 활성 레인은 위험군, 회피 기호, 보상 역할을 결합해 `바닥→↑점프 · 충전+1`, `상단→↓숙이기 · 반격+50`, `측면→↔비틀기 · 연쇄+1`처럼 중앙 설명을 읽지 않아도 대응과 정확 타이밍 이득을 식별하게 한다

- 타이틀·연결·입구 로비에는 `Resources/GreedLast/PrototypeEntrance` 16:9 시안 한 장을 낮은 명암으로 사용한다. 타이틀에서 가장 선명하고 연결 화면과 로비로 갈수록 약해지며, 런 진입 때는 동적 통로 뒤에서 짧게 페이드아웃한 뒤 완전히 비활성화한다. 저장·기록 화면에서도 숨겨 본문 가독성을 침범하지 않는다.
- 입구 배경은 정면 직선 통로, 실제 세 레인, 도깨비 소녀의 작은 뒷모습을 한 화면에서 보여 `템플런식 전진 + 놈식 제한 회전 + 리듬 대응`의 출발 방향을 첫 화면에 고정한다. 최종 원화가 들어오면 같은 리소스 자리에서 교체한다.
- 주자 파츠 변형은 최종 캐릭터 애니메이션이 아니라 프로토타입 확인용 실루엣 기준이다. 정식 아트가 들어오면 같은 동작 방향만 유지하고 파츠 표현은 교체할 수 있다.
- 이 그래픽 패스는 판정, 점수, 저장, 무한모드 로직을 바꾸지 않으며, 나중에 정식 캐릭터 / 함정 / 배경 에셋이 들어올 때 대체될 프로토타입 표현으로 둔다.

## 2026-10-11 키보드 전환 경계

- 일시정지/종료 스냅샷이 처음 발행된 실제 재생 프레임의 Esc/P/Enter는 새 메뉴의 명령으로 재사용하지 않는다. 키 없음은 그대로 미처리이며 다음 프레임의 새 키는 기존 재개 카운트·재시작·결과 복귀를 수행한다. 추가 시간 지연이나 타이밍/저장 규칙 변경은 없다.

## 2026-10-12 선택 진입과 소리 수신기

- 처음 런 선택이 열리거나 선택 종류가 바뀐 실제 재생 프레임의 레인 입력은 보지 못한 선택에 적용하지 않는다. 다음 프레임의 새 선택과 기존 연타/진입 보호는 유지하며 판정 폭·선택 효과·저장 규칙은 바꾸지 않는다.
- 카메라와 AudioListener는 별도 소유 자원이다. 초기 화면/씬 복구 때 외부 활성 수신기가 있으면 그대로 쓰고, 없을 때만 앱 소유 임시 수신기 하나를 만든다. 외부 수신기의 enabled나 전역 소리 설정은 변경하지 않는다. 씬 인계/앱 종료에서 임시 수신기만 즉시 비활성화 후 정리한다. 매 프레임 탐색은 하지 않으며 실제 소리 출력·지연 검증과 구분한다.

## 2026-10-12 동시 키 확정과 검사 설정 비교

- 저장 슬롯·무한 슬롯·무한 정비에서 방향키와 Enter가 동시에 들어오면 방향 선택이 우선이다. 이전 칸 저장이나 정비 재선택 전 실제 시작을 하지 않으며 별도로 새 Enter를 눌러야 확정한다. 기존 레인 별칭과 좌→중→우 우선순위, 주행 Enter 우선순위는 유지한다.
- 엔진 검사 개인 설정 비교에는 백엔드 진행·온보딩·네 감각 설정뿐 아니라 입력 보정 키도 포함하고 실제 키 목록을 보고서에 기록한다. 앞선 목록에서 보정 키가 빠졌던 것은 비교 범위 누락이며 값 변경의 증거가 아니다. 개인 키를 쓰는 대신 비교 목록만 읽기 보완한다.

## 2026-10-12 시스템 단축키와 게임 키

- Control·Alt/AltGr·Windows/Command가 눌린 동안은 게임의 키보드 명령/레인/개발 키를 처리하지 않는다. Shift와 기본 키는 기존대로이며 센서·마우스/터치·코어 시간 진행은 이 키보드 조건과 분리한다. 실제 OS 단축키 동작/키보드 장치 확인과 여덟 불리언 조합 검사를 구분한다.

## 2026-10-12 화면 발행 프레임과 새 명령

- 화면 상태/슬롯 표시를 새로 발행한 재생 프레임에는 키보드 확정·뒤로와 레인 선택을 새 표시의 명령으로 재사용하지 않는다. 다음 엔진 프레임의 새 입력은 정상이다. 런 정지/결과·런 선택의 별도 스냅샷 보호도 유지하며 추가 시간 잠금은 만들지 않는다.
- 상태 표시 콜백은 앱이 소유하며 UI 제거/앱 종료 때 함께 해제한다. 검사에서도 실제 앱의 같은 상태 표시 콜백을 사용한다.
- 슬롯 선택을 검사할 때는 선택을 유지하는 `LoadSelectedSaveSlotView`를 사용한다. `LoadLobby`는 후보/무한 추천 슬롯 선택을 수행하는 의도된 로비 동작이므로 직접 고른 칸의 읽기 전용 검사에 쓰지 않는다. 테스트가 선택을 바꾸던 실패와 실제 입력 경계 재현을 구분해 보존한다.
