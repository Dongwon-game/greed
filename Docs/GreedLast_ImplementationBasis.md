# Greed Last 구현 기준

## 제작 원칙

- 기존 `C:\Projectunity\greed\greed` 코드는 새 프로젝트로 가져오지 않는다.
- `C:\Projectunity\greeddata\summary` 문서를 실제 구현 기준으로 둔다.
- 6-5 백업 브랜치는 최종 방향 참고용으로만 본다.
- 새 구현은 Unity 6.4 프로젝트 `greed last`에서 6-1부터 다시 만든다.

## 게임 감각

- 장르: 모바일 리듬 탈출게임
- 핵심 감각: 함정을 피하며 앞으로 나아가고, 정확한 타이밍 입력으로 더 높은 점수와 흐름 이점을 얻는다.
- 입력 기준: 좌 / 중 / 우는 이동 위치가 아니라 위험 대응 채널이다.
- 레퍼런스 감각: 박자에 맞춰 행동하는 액션, 정확 타이밍 방어 보상, 오래된 모바일 회피 러너의 직관성.

- 함정 마커 주변에 글로우와 타격선을 추가해 판정선에 가까워질수록 피해야 하는 느낌을 강화
- Perfect / Clutch / Offbeat 함정은 색과 타격선 각도를 달리해 패턴 성격을 시각적으로 구분
- 좌 / 중 / 우 시작 큐는 채널 안내로 유지하고, Perfect / Clutch / Offbeat 코어 큐는 서로 다른 톤으로 분리
- 무한모드 위협 단계가 높을수록 코어 큐 볼륨이 조금 커져 긴장감을 보강
- 콤보 3 이상 Success에는 연쇄 성공음을 추가해 리듬 보상감을 강화
- 에디터 / 개발 빌드 런 화면의 오른쪽 테스트 패널에 `소리 -` / `소리 0~100` / `소리 +` 버튼을 추가
- 테스트용 효과음 볼륨은 PlayerPrefs에 저장해 에디터 재시작 뒤에도 유지
- 모바일 빌드에서는 Success / Good / Miss / 연쇄 Success에 짧은 진동 피드백을 적용
- 에디터 / 개발 빌드 런 화면에 `진동 ON/OFF` 테스트 토글을 추가하고 PlayerPrefs에 저장
- 런 화면 오른쪽에 `일시정지` / `재개` 버튼 추가
- 일시정지 중에는 거리 증가, 자동 진행, 활성 함정 타이머, 박자 효과음 진행을 멈춤
- 재개 시 함정 시작 시각 / 다음 함정 예약 / 경직 종료 시간을 보정해 일시정지 때문에 늦음 판정이 나지 않게 함
- `재개`를 누르면 바로 이어지지 않고 짧은 재개 카운트인을 거친 뒤 활성 함정을 앞 박자만큼 되감아 다시 내려오게 함
- 재개 카운트인 중에는 버튼을 `재개 준비`로 잠그고 카운트 박자음을 재생
- 재개 카운트인 중 중앙 판정 피드백 영역에 큰 `2 / 1 / GO` 표시를 띄워 다시 들어가는 박자를 명확히 보여줌
- 무한모드 시작, 선택 확정 후 챕터 시작, 공명핵 회수 후 탈출 검증 시작에도 같은 `2 / 1 / GO` 시작 카운트인을 적용
- 시작 카운트인 중에는 진행 / 테스트 버튼과 레인 입력을 잠그고, 카운트가 끝난 뒤 첫 함정을 내려보냄
- PC / 에디터 테스트에서 `Esc`로 즉시 일시정지 메뉴를 열고, 다시 `Esc` 또는 중앙 `재개` 버튼으로 재개 카운트인에 들어감
- 일시정지 상태에서는 중앙 큰 버튼이 `재개`로 바뀌고, `로비로` 버튼으로 현재 런을 중단할 수 있음
- 모바일 앱이 백그라운드로 전환되면 진행 중인 런을 자동 일시정지
- `Esc` 일시정지 메뉴는 배경을 어둡게 눌러 주변을 흐릿하게 느끼게 하고, 중앙에 별도 패널 오버레이로 표시
- 일시정지 패널에서는 중앙 `재개` / `로비로` 버튼을 메뉴 위치로 재배치하고 오른쪽 테스트 도구는 숨김
- 런 화면에 체력 / 집중 게이지를 추가해 체력 0 위험과 집중 MAX 상태를 텍스트 HUD 없이도 즉시 볼 수 있게 함
- 런 화면 상단에 챕터 / 탈출 검증 / 무한 구간 진행 바를 추가해 현재 전진 흐름과 위협 단계를 즉시 볼 수 있게 함
- 런 화면 중앙 상단에 콤보 / 연쇄 배지를 추가해 Success가 이어질 때 리듬 보상감을 별도 UI로 확인할 수 있게 함
- 런 중 레인 배경에 박자 기반 전진 모션 라인을 추가해 정적인 판정판보다 앞으로 달리는 느낌을 보강
