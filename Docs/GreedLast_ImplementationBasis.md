# Greed Last 구현 기준

테스트 순서는 `Docs/GreedLast_Prototype_Checklist.md`에 따로 정리한다.

## 제작 원칙

- 기존 `C:\Projectunity\greed\greed` 코드는 새 프로젝트로 가져오지 않는다.
- `C:\Projectunity\greeddata\summary` 문서를 실제 구현 기준으로 둔다.
- 6-5 백업 브랜치는 최종 방향 참고용으로만 본다.
- 새 구현은 Unity 6.4 프로젝트 `greed last`에서 6-1부터 다시 만든다.
- 코어 플레이 대조는 `10_Pyramid_Greed_Core_Play_and_Level_Reference_Final`과 `23_Pyramid_Greed_Stage_Chapter_Trap_Reference_Final`의 챕터 역할 기준을 우선한다.

## 게임 감각

- 장르: 모바일 리듬 탈출게임
- 핵심 감각: 함정을 피하며 앞으로 나아가고, 정확한 타이밍 입력으로 더 높은 점수와 흐름 이점을 얻는다.
- 입력 기준: 좌 / 중 / 우는 이동 위치가 아니라 위험 대응 채널이다.
- 레퍼런스 감각: 박자에 맞춰 행동하는 액션, 정확 타이밍 방어 보상, 오래된 모바일 회피 러너의 직관성.

## 6-1 구현 범위

- BootInit
- ConnectChecking
- ConnectBlocked
- LobbyLoading
- LobbyReady
- ReSyncPending
- Retry Sync
- 첫 저장 전 무한모드 비노출
- 저장 조합 진입 직전 최신 상태 재검사 자리만 준비

## 6-2 구현 범위

- 로비의 일반 런 버튼에서 함정 대응 검증 화면 진입
- 좌 / 중 / 우 3채널 입력
- 모바일 터치용 좌 / 중 / 우 입력 영역
- 에디터 테스트용 A / S / D 입력
- 단일 활성 함정 패턴
- 좌 / 중 / 우 함정 패턴 9종 순환
- Perfect / Clutch / Offbeat 전용 타이밍 성공
- Good 생존 완충
- Miss 피해 + 짧은 경직
- 최초 입력만 반영
- 점수 / 체력 / 콤보 / 집중 게이지 최소 표시
- 런 화면 전용 메트로놈 클릭음
- 함정 마커가 판정선으로 내려오는 예고 연출
- 판정선 근처에서 밝아지는 타이밍 시각화
- Success / Good / Miss별 짧은 효과음과 화면 플래시
- 패턴별 코어 타이밍 위치에 판정선을 동적으로 배치
- Good / Success 입력 가능 범위를 반투명 타이밍 띠로 표시
- 함정 시작 시 좌 / 중 / 우 채널별 다른 큐 사운드 재생
- 코어 타이밍 직전 타깃 큐 사운드 재생
- HUD와 하단 가이드에 준비 / 지금 / 늦음 타이밍 상태 표시
- Success 타이밍 띠는 실제 입력 채널에 집중 표시
- Good 타이밍 띠는 전체 기준선으로 낮은 투명도 표시
- 타깃 큐 사운드는 코어 타이밍 약 0.14초 전에 재생
- 활성 함정 중 메트로놈 볼륨을 낮춰 큐 사운드와 판정음을 덜 가리게 조정
- 코어 타이밍 직전 타깃 큐에는 낮은 볼륨의 점프 / 숙이기 / 비틀기 액션 큐도 함께 섞어 지금 누를 동작을 소리로 한 번 더 확인하게 한다
- 타깃 액션 큐 사운드는 정박 충전 / 압박 반격 / 엇박 연쇄 / 복구 같은 특수 보상 타이밍에서만 아주 작게 강조해 보상 큐를 듣기 쉽게 한다
- 활성 액션 큐는 회피 동작 / 입력 / 박자와 함께 정확 점수, Good 보정 점수, 정박 충전·압박 반격·엇박 연쇄 같은 특수 보상을 한 줄로 미리 보여준다
- 입력 후 Success / Good / Miss 결과를 중앙 하단에 짧게 크게 표시
- 입력 타이밍 차이를 정확 / 빠름 Nms / 늦음 Nms로 표시
- 콤보 3 이상부터 Success 시 `연쇄 박자` 보너스 점수와 HUD 연쇄 배율 표시
- Good / Miss로 연쇄가 끊기면 판정 문구에 `연쇄 끊김` 표시
- 생존 가능한 Miss 뒤에는 판정 여유가 있는 복구 함정을 1회 배치
- 복구 함정 중앙 정박은 `복구 정박`으로 판정해 점수 +75, 집중 +1, 콤보 +1 추가 보상
- 복구 함정 Good은 생존 흐름만 유지하고 중앙 정박 추가 보상은 주지 않음
- Perfect 함정 중앙 정박은 `정박 충전`으로 판정해 집중 +1 추가 보상
- Clutch 함정 중앙 정박은 `압박 반격`으로 판정해 점수 +50 추가 보상
- Offbeat 함정 중앙 정박은 `엇박 연쇄`로 판정해 콤보 +1 추가 보상
- 복구 정박 / 압박 반격 / 엇박 연쇄 횟수를 런 기록과 결과 흐름에 보존
- 프로필 장식 화면에 정박 충전 / 압박 반격 / 엇박 연쇄 최고 숙련과 배지 진행을 표시
- 안정 루트는 넓은 판정에 더해 Good 성공 시 손실 체력을 1 회복해 실수 복구 역할을 분명히 한다
- 변주 루트는 엇박 함정을 우선 배치하고 중앙 정박 시 집중을 1 추가해 엇박 운용 보상을 준다
- 압박 루트는 Clutch 함정을 우선 배치하고 중앙 정박 반격 점수에 35점을 추가해 좁은 판정의 고점을 보상한다
- 안정 복구 / 변주 공명 / 압박 증폭 횟수는 런 기록과 결과 흐름에 보존한다
- 경로 선택지, 활성 코치, 런 목표, 중앙 판정 피드백은 같은 경로 보상 규칙을 안내한다
- 안정 복구는 초록 회복 피드백, 변주 공명은 보라색 집중 피드백, 압박 증폭은 주황색 고점 피드백으로 구분한다
- 경로 보상 발동음과 진동 강도도 회복 / 변주 / 압박 성격에 맞춰 분리한다
- 경로 보상 진동은 안정 복구 < 변주 공명 < 압박 증폭 순서로 강해지며, 목표 달성 순간에는 한 단계 더 강한 펄스로 검증한다
- 저장 조합의 지배 경로를 무한모드에 복원하면 같은 안정 / 변주 / 압박 지속 보상이 유지된다
- 현재 경로는 런 스냅샷의 정식 상태로 유지하고 챕터 제목과 하단 상태 안내에 계속 표시한다
- 각 경로의 첫 함정은 안정 Perfect / 변주 Offbeat / 압박 Clutch 성격을 우선 제시해 선택 결과를 즉시 체감하게 한다
- 경로 선택 칸과 첫 함정 예고는 Good 회복 +1 / 엇박 집중 +1 / Clutch 점수 +35 수치를 동일하게 표시한다
- 일반 런과 무한모드 종료 HUD에 실제 발동한 안정 / 변주 / 압박 경로 보상 횟수를 한 줄로 정산한다
- 결과 강점 분석은 선택한 경로 이름만 보지 않고 안정 복구 / 변주 공명 / 압박 증폭 실제 발동 횟수를 우선한다
- 에디터 / 개발 빌드 오른쪽 도구에 `경로 안정 ↑↓↔ → 경로 변주 ↔↓↑ → 경로 압박 ↓↔↑` 순환 체험 버튼과 F8 단축키를 제공한다
- 경로 체험은 2장 대표 함정 직전으로 이동하고 점수 / 판정 / 거리 기준을 초기화해 세 경로를 같은 조건에서 비교하게 한다
- 경로 체험 대표 함정은 안정 Perfect / 변주 Offbeat / 압박 Clutch로 시작하며 본게임 빌드에는 노출하지 않는다
- 프로필 장식 화면에 안정 복구 / 변주 공명 / 압박 증폭 최고 기록과 3회 달성 배지를 표시한다
- 타이밍 축 숙련 뒤에는 세 경로 보상 3회 달성을 다음 흔적 목표로 순서대로 안내한다
- 경로 추천은 첫 구간 실수 / 보정이면 안정, 첫 구간 완전 정확이면 압박을 유지한다
- 안정 경로에서 다음 구간을 정확하게 돌파하면 변주를 `안정 졸업` 단계로 추천한다
- 변주 경로까지 완전 정확으로 돌파하면 압박 고점 경로를 다음 단계로 추천한다
- 2~3장의 기본 3함정 배열은 안정 `Perfect-Clutch-Perfect`, 변주 `Offbeat-Perfect-Offbeat`, 압박 `Clutch-Offbeat-Clutch`로 구분한다
- 3장 가운데 함정은 선택 유물의 Perfect / Offbeat / Clutch 성격을 우선해 경로 리듬에 유물 변화를 섞는다
- 같은 경로의 3함정을 모두 정확으로 통과하면 경로 전용 완주 보상을 지급한다
- 안정 완주는 체력 +1, 변주 완주는 집중 +2 또는 집중 상태 연장, 압박 완주는 점수 +150과 집중 흐름을 지급한다
- 진행 HUD는 `안정/변주/압박 완주 N/3`을 표시하고 마지막 함정 목표에 받을 완주 보상을 미리 표시한다
- 완주 순간의 화면 플래시 / 합성음 / 진동 / 전환 라벨은 안정 초록, 변주 보라, 압박 주황으로 구분한다
- 안정 완주 / 변주 완주 / 압박 완주 횟수는 런 기록, 종료 정산, 결과 강점, 프로필 경로 완주에 보존한다
- 경로 3함정 중 Good 또는 Miss가 처음 발생하면 `안정/변주/압박 완주 중단`을 즉시 표시하고, 남은 구간 HUD에도 중단 상태를 유지한다
- 안정 경로의 Good 체력 회복 같은 개별 보상은 완주 중단 뒤에도 정상 지급하되 3함정 정확 완주 보상과 분리한다
- 노드 선택 화면은 안정 `정-압-정`, 변주 `엇-정-엇`, 압박 `압-엇-압` 박자 지도를 한 줄로 비교한다
- 2~3장 중앙 설명은 현재 경로의 3박 배열을 표시하고 진행 중인 박자만 `[정]`, `[압]`, `[엇]`으로 강조한다
- 3장에서는 선택 유물이 바꾼 가운데 박자를 경로 지도에도 즉시 반영하고 `유물 변주`로 이름을 붙인다
- 구간 판정 기반 경로 추천 이유에는 추천 경로의 3박 배열을 함께 표시해 다음 연습 내용을 바로 알 수 있게 한다
- 경로 함정 1·2번째 판정 직후 중앙 피드백과 코치에 현재 `N/3`, 다음 박자, 마지막 완주 보상을 이어서 표시한다
- Good 또는 Miss 뒤에는 다음 박자를 `연습`으로 안내해 남은 함정은 계속 읽되 이번 구간 완주 보상은 끊겼음을 구분한다
- 4장 공명핵 구간과 탈출 검증도 고정 `압-엇-정` 배열의 현재 박자, 다음 박자, 경로 완주 보상을 같은 방식으로 안내한다
- 상단 진행 바 안에는 3칸 경로 박자 표시를 두고 완료 / 현재 / 대기 / 완주 중단 상태를 색과 크기로 구분한다
- 챕터 3은 기프트·유물·연속 대응이 가장 강하게 살아나는 `변주 정점`으로 표시한다
- 챕터 4와 탈출은 새 규칙을 추가하는 구간이 아니라 기존 `압-엇-정`을 끝까지 증명하는 `공명핵/탈출 검증`으로 표시한다
- 최종 검증 구간은 챕터 3보다 빨라지지 않도록 기본 템포 시간을 4% 늘리고 판정 폭을 5% 넓혀 혼합 읽기에 집중시킨다
- 상단 진행 바는 챕터 1 `학습`, 챕터 2 `방향 형성`, 챕터 3 `변주 정점`, 챕터 4 `공명핵 검증`, 마지막 `탈출 검증` 역할을 함께 표시한다
- 챕터 마지막 함정의 정밀 보상 문구는 선택 화면 전환 뒤에도 중앙 피드백에 유지
- 입력 판정 보정값을 ±200ms 범위에서 20ms 단위로 조정
- 보정값은 PlayerPrefs에 저장해 에디터 재시작 뒤에도 유지
- 오른쪽 테스트 패널에서 빠름 +20 / 보정 0 / 늦음 -20 버튼 제공
- 판정 계산에는 보정값을 반영하고, 시각 마커와 판정선은 원래 박자 기준 유지
- HUD에 현재 입력 보정값 표시
- 채널 오류는 입력 채널과 정답 채널을 함께 표시
- 기초연습은 `Perfect → Clutch → Offbeat` 세 축을 고정 순서로 생성해 안내 문구와 실제 함정이 항상 일치하게 한다
- 기초연습 제목·목표·진행 바는 `정박 바닥→↑점프`, `클러치 상단→↓숙이기`, `엇박 측면→↔비틀기`와 각 목표 줄로 현재 위험군, 동작, 타이밍 축을 각각 표시한다
- 기초연습 상단 진행 바도 3칸 타이밍 색을 사용하고 지나간 단계 / 현재 단계 / 대기 단계를 구분한다
- 기초연습 완료는 실수 포함 시 `실수 구간 다시`, Good만 포함 시 `정확권 다시`, 전부 정확 시 `3축 다시 확인`으로 재시작 행동을 구분한다
- 기초연습 판정은 일반 런 챕터 기록과 저장 후보를 만들지 않으며, 전부 정확해도 일반 런용 묶음 보상은 지급하지 않는다
- 기초연습의 유효 타이밍 샘플이 3회 모이면 완료 화면에 현재 보정 안정 또는 추천 입력 보정 값을 표시한다
- 기초연습 종료 상태에서는 수동 ±20ms 버튼은 잠그고, 실제 차이가 있는 가운데 `추천 적용` 버튼만 사용할 수 있게 한다
- 집중이 최대치일 때 Miss가 나면 체력 피해 대신 집중을 전부 소모해 1회 보호
- HUD에 집중 보호 준비 / 충전 상태 표시
- 오른쪽 테스트 패널에서 `집중 발동` / `집중 리필` 버튼으로 집중 보호 검증 상태를 즉시 만들 수 있음
- 자동 시작 / 정지 흐름
- 함정 종료 후 러닝 복귀 간격을 둔 자동 다음 패턴 생성
- 진행 거리 표시
