# Greed PC 체험 안내

기획서를 읽는 사람이 Windows PC에서 대표 한 판을 체험하는 안내다. **모바일 빌드/검증은 현재 목표가 아니다.** Unity나 Android 모듈 설치 없이 Windows 실행본을 사용한다.

## 실행

현재 Unity 프로젝트는 `C:\Users\ehddn\OneDrive\문서\ChatGPT\greed`다. Windows 체험본은 이 폴더의 `Builds/PCReview-current.json`에 기록한 실행 파일과 ZIP을 사용한다. 해당 파일이 없다면 새 체험본 배포가 끝난 상태가 아니므로 Unity에서 시작하거나 [확인 이력](GreedLast_Prototype_CheckHistory.md)의 실제 검증된 사본 위치를 확인한다.

실행 파일만 떼어 전달하지 않고 ZIP을 푼 전체 폴더를 유지한다. 공개 GitHub에는 실행 파일/ZIP과 개인 저장이 없고 소스·그림·문서만 있다. 포맷 전 `C:\Projectunity\greed last`와 Demo31 파일명은 과거 기록이며 현재 PC의 실행 경로가 아니다.

현재 체험본은 개인 게임과 저장 공간이 다르다. **같은 체험본을 다시 열면 해당 체험 진행은 유지**한다. 처음 화면과 다르더라도 저장을 지우지 말고 로비의 연습을 선택한다. 개인 진행을 복원·이전하거나 기존 Demo31 저장과 합친 제품이라는 뜻은 아니다. [체험 실행본 안내](GreedLast_Prototype_Demo.md)에 저장 분리와 남은 확인을 정리했다.

개발 브랜치의 후속 변경과 현재 체험본의 소스는 실행 파일 식별 정보로 구분한다. 11월 6일 안내 수정과 검증 대기 항목은 [PC 안내 후속](PC-Guidance-20261106.md)에 기록한다.

11월 9일 종료 조작과 새 함정 키 안내를 확인하려면 개발 사본의 `Builds/GreedLastPCReviewCandidate-20261109-7cb1d41/GreedLastPrototype.exe`를 연다. 같은 이름의 ZIP과 `PCReview-candidate-20261109-7cb1d41.json`에 파일 검증과 검사 범위를 기록했다. 종료 조작 버전은 숨김 Windows 프로세스에서 통과했고 최신 후보는 세 방향 함정의 키 표시와 저장 재실행을 확인했다. [종료 조작 검증 상태](PC-Exit-Controls-20261108.md)

11월 8일 후보 `Builds/GreedLastPCReviewCandidate-20261108-878b01c`에서는 실제 프로필 키 이동, 저장 비교 드래그와 포커스 복귀, 정상 종료와 저장 재실행을 확인했다. [키보드 검증 기록](PC-Menu-Keyboard-20261108.md)

앞선 `Builds/GreedLastPCReviewCandidate-20261108-1d8738e`와 해당 인계 JSON도 보존한다. [움직임 수정 기록](Motion-Clock-20261108.md)과 [정지 배경 후속](Pause-Scenery-20261108.md)은 소스별 결과를 구분한다. 기존 체험본의 진행을 옮기거나 지우지 않고 각 후보의 별도 저장 공간으로 시작한다.

Q/E는 현재 실행본에서 개발 확인용이므로 체험자 공통 조작으로 안내하지 않는다. 좌·중·우는 이동 레인이 아니라 위험에 대응하는 채널이다. PC 실행본의 레인·회전·오입력 안내는 실제 키보드 입력을 기준으로 확인한다. 처음 기초 연습 전에는 같은 채널 대응과 판정선 입력을 읽는다.

## 대표 한 판

1. 타이틀 → 입구 → 연습에서 바닥 가시/상단 칼날/측면 날과 점프/숙이기/비틀기를 본다. 첫 연습 안내가 표시되면 Enter 또는 화면의 연습 버튼으로 시작한다.
2. 함정이 표시된 채널을 판정선에 맞춰 누른다. 점프·숙이기·비틀기는 함정에 따라 나오는 회피 동작이다. 같은 채널에서 정확과 Good의 소리·점수·집중 차이를 비교한다.
3. 주행 중 ESC/P로 정지 메뉴를 열고, 재개 카운트와 앞 여유 뒤 같은 구간을 잇는지 본다. 선택 화면에서는 일시정지 대신 화면의 좌·중·우 선택을 사용한다.
4. 로비 → 일반 런에서 시작 기프트를 고른다. 1~3장에서는 각 장의 루트와 마감 기프트를 한 번씩 선택하고, 2장 마감 기프트 뒤에는 유물을 한 번 고른다. 직선 주행과 짧은 회전을 체험한다.
5. 공명핵 회수 뒤 탈출 게이트까지 통과하고 클리어 요약을 본다. 저장하지 않으면 `저장 없이 로비`로 마친다.

저장/무한까지 볼 때만 원하는 칸 한 번 저장 → 정비 취소 무소모 → 실제 두 번 시작/자동 비움 → 기록을 이어서 본다. 보관할 개인 조합을 테스트로 소모하지 않는다. 자세한 순서는 [빠른 확인](GreedLast_Prototype_QuickCheck.md)에 있다.

## 마무리 기준

앞으로 달리는 방향, 세 회피의 구분, 정확 타이밍의 이득, 짧은 회전의 편안함, 탈출/결과 연결을 PC에서 판단한다. 자동 검사·카메라 자료가 손맛 확인을 대신하지 않는다. 이 최종 플레이에서 발견한 문제만 조정하며 모바일 작업이나 길드·계정·결제 UI를 완료 조건으로 추가하지 않는다.
