# Greed PC 체험 안내

기획서를 읽는 사람이 Windows PC에서 대표 한 판을 체험하는 안내다. **모바일 빌드/검증은 현재 목표가 아니다.** Unity나 Android 모듈 설치 없이 Windows 실행본을 사용한다.

## 실행

이 PC에서는 `C:\Projectunity\greed last\Builds\GreedLastDemo-20261031\GreedLastDemo.exe`를 연다. 다른 PC로 전달할 로컬 묶음은 `Builds\GreedLastDemo-20261031-entrance-pause.zip`이다. 실행 파일만 떼어 전달하지 않고 ZIP을 푼 전체 폴더를 유지한다. 현재 공개 GitHub에는 실행 파일/ZIP이 없고 소스·그림·문서만 있다.

체험판은 개인 게임과 저장 공간이 다르지만 **기존 체험 진행은 유지**한다. 처음 화면과 다르더라도 저장을 지우지 말고 로비의 연습을 선택한다. 현재 실행본 식별/보존 범위는 [체험 실행본 안내](GreedLast_Prototype_Demo.md)를 따른다.

## 조작

| 동작 | PC 입력 |
| --- | --- |
| 좌 / 중 / 우 대응·선택 | A / S / D, 방향키 또는 화면의 해당 영역 클릭. Space는 중 |
| 회전 통로 | 해당 방향 A/왼쪽 또는 D/오른쪽, 해당 영역 클릭 |
| 일시정지 / 새 재개 | ESC 또는 P, 화면 버튼 |
| 메뉴 뒤로 / 강조 동작 | ESC / Enter. 선택과 확정은 따로 입력 |

Q/E는 현재 실행본에서 개발 확인용이므로 체험자 공통 조작으로 안내하지 않는다. 좌·중·우는 이동 레인이 아니라 위험에 대응하는 채널이다. 화면의 일부 모바일/탭 문구는 이전 범용 UI 표기이며 PC용 표시 정리는 후속 대상이다. 모바일 검증을 해야 진행할 수 있다는 뜻이 아니다.

## 대표 한 판

1. 타이틀 → 입구 → 연습에서 바닥 가시/상단 칼날/측면 날과 점프/숙이기/비틀기를 본다.
2. 같은 채널을 판정선에 맞춰 눌러 정확과 Good의 소리·점수·집중 차이를 비교한다.
3. ESC/P → 정지 메뉴 → 새 재개에서 카운트와 앞 여유 뒤 같은 구간을 잇는지 본다.
4. 로비 → 일반 런에서 시작 기프트·장 마감 루트/기프트·유물을 고르고 직선 주행과 짧은 회전을 체험한다.
5. 공명핵 회수 뒤 탈출 게이트까지 통과하고 클리어 요약을 본다. 저장하지 않으면 `저장 없이 로비`로 마친다.

저장/무한까지 볼 때만 원하는 칸 한 번 저장 → 정비 취소 무소모 → 실제 두 번 시작/자동 비움 → 기록을 이어서 본다. 보관할 개인 조합을 테스트로 소모하지 않는다. 자세한 순서는 [빠른 확인](GreedLast_Prototype_QuickCheck.md)에 있다.

## 마무리 기준

앞으로 달리는 방향, 세 회피의 구분, 정확 타이밍의 이득, 짧은 회전의 편안함, 탈출/결과 연결을 PC에서 판단한다. 자동 검사·카메라 자료가 손맛 확인을 대신하지 않는다. 이 최종 플레이에서 발견한 문제만 조정하며 모바일 작업이나 길드·계정·결제 UI를 완료 조건으로 추가하지 않는다.
