# Greed 기획 체감 범위

원본 기획 대조 기준은 2026-10-04~05를 유지하고, 흐름 검증은 2026-10-15 소스 `11dda62`까지 갱신했다. 목표는 상용 게임 전체 구현이 아니라 시작 화면부터 일반 런의 회피/리듬 이득과 저장/무한 연결을 직접 체감하는 프로토타입이다. 완성도 백분율 대신 아래의 실제 흐름과 남은 확인으로 판단한다.

## 흐름 확인과 체감 확인

타이틀→입구→연습/일반→루트·기프트·유물→공명핵→탈출→원하는 칸 한 번 저장→정비 취소/실제 무한 두 번→자동 비움/기록의 대표 흐름은 구현되어 있다. 두 재생 방식의 실제 엔진 프레임/합성 입력 검사도 통과했다. 선택 체력 상한과 완주 집중 대체·회복/점수/위협 안내가 실제 결과와 같은지 확인하며, 이를 손맛이나 휴대폰 성능 통과로 표시하지 않는다. 상세 근거와 현재 실행본은 [빠른 확인](GreedLast_Prototype_QuickCheck.md)을 따른다.

직접 플레이에서는 아래 다섯 가지를 우선한다. 기본 표시에서 먼저 보고 필요한 부분만 F11 상세로 확인한다.

1. **직선 주행**: 메뉴를 보지 않아도 앞으로 달리는 방향과 캐릭터 위치가 읽히는가.
2. **함정 대응**: 바닥/머리 위/측면 위험을 미리 구분하고 같은 채널의 점프/숙이기/비틀기로 피했다고 느껴지는가.
3. **정확 타이밍의 이득**: 생존하는 Good과 정박의 점수·집중/연쇄 보상이 구분되고, 정확히 누르는 것이 더 이롭다고 느껴지는가.
4. **제한된 회전**: 회전 통로만 짧게 기울고 HUD/판정선은 고정되어, 방향 전환의 변주가 읽히면서 어지럽지 않은가.
5. **한 판의 마무리**: 공명핵만으로 끝나지 않고 탈출 뒤 결과/저장 선택이 자연스럽게 이어지는가. 무한 두 번째 사용 뒤 슬롯이 비어도 시작한 런은 계속되는가.

이 다섯 항목의 아쉬움을 다음 수정 기준으로 삼는다. 기획 체감 목표를 위해 길드·계정·결제·운영 화면을 추가하거나 자동 검사 수치만 늘릴 필요는 없다. 회복/피해/집중 보호·판정 폭/보상 가중치를 새로운 감각 확인 없이 함께 바꾸지 않는다.

## 의도적으로 줄인 범위

- 원본 23번의 4스테이지×4챕터 전체 분량은 만들지 않았다. 현재 일반 런은 4장과 탈출 검증의 대표 한 판으로 학습→방향→변주→증명을 압축한다.
- 원본 27번의 기본 4칸/성장 5칸/확장 3회 사용은 만들지 않았다. 현재 세 채널에 맞춘 3칸과 각 2회만 사용한다.
- 사용 후 조합을 기록 상태로 보관한다는 원본 27번 대신, 이후 사용자 요청대로 두 번째 실제 시작 때 슬롯을 자동으로 비운다. 시작한 런과 별도 플레이 기록은 유지한다.
- 그림은 도깨비 소녀/피라미드/함정 종류를 읽는 1차 체감용이다. 정식 캐릭터 애니메이션, 수록곡, 상용 모바일 최적화는 아니다.
- 길드/계정/결제/서버/시즌 운영 UI를 목표에 포함하지 않는다.

## 기획 차이를 남겨 둘 것

원본 24번은 집중 상태를 고점 유지 보조로 두고 피해 무효 같은 생존 보험을 제외한다. 현재 구현에는 집중 최대치 소모의 1회 보호가 남아 있고 앞선 집중 보호 확인 흐름에도 사용됐다. 이는 원본과 같은 것으로 표시하지 않는다. 이번 무한 동작 선호 수정에서 보호/점수/판정 폭을 함께 바꾸지 않았다. 기획 체감 검토 때 이 차이를 별도로 판단한다.

## 남은 실제 확인

- 새 무한모드의 패턴이 일반 1장의 동작 선호에 묶이지 않는지, 그래도 위험/동작/박자가 읽히는지 손으로 확인한다. 일반/연습/탈출의 기존 동작 배열은 유지한다.
