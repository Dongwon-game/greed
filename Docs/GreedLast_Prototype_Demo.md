## 눌러볼 순서

1. **타이틀 → 입구 → 기초 연습**: 이집트 인간 주자와 앞으로 달리는 통로를 본다. 좌/중/우는 이동 레인이 아니라 위험과 같은 대응 채널이다.
2. **점프 → 숙이기 → 비틀기**: 판정선을 보고 A/S/D 또는 해당 채널을 누른다. 동작 그림과 단계 제목이 맞아야 한다. 마지막 연습 판정 뒤 곧바로 결과로 넘어가는 것은 정상이다.
3. **연습 중 ESC/P → 재개**: 별도 정지 메뉴 뒤 새 재개 입력, 카운트와 앞 여유를 확인한다. 정확/Good의 차이와 소리는 여기서 비교한다. 보정은 직접 체감한 값만 쓰고 미리보기의 합성 -200ms를 따라 적용하지 않는다.
4. **로비 → 일반 런 → 시작 기프트**: 2초 이상 기다렸다가 원하는 기프트를 고른다. 그때 입구를 넘어 출발 카운트로 이어져야 한다. 장 마감 루트/기프트와 중반 유물도 각각 고르고 정확의 점수·집중 이득과 짧은 회전을 본다. 실패하면 새 런으로 다시 시도한다.
5. **공명핵 → 탈출 게이트 → 클리어 요약**: 핵만 얻었다고 끝나지 않아야 한다. `저장 슬롯 선택`으로 가거나 `저장 없이 로비`를 고른다.
6. **저장할 칸 선택 → 확정**: S2/S3 등 원하는 칸에 이번 후보를 한 번만 저장한다. 관리에 다시 들어가도 같은 후보를 두 번 저장할 수 없어야 한다.
7. **무한 정비 → 취소 → 다시 준비 → 실제 시작**: 취소는 2회 그대로, 실제 첫 시작만 2→1이다.
8. **자연 종료 → 재준비 → 두 번째 실제 시작**: 칸이 자동으로 비어도 시작한 런은 계속되어야 한다. 체험판 조합이므로 보관할 개인 조합은 소모하지 않는다.
9. **로비 → 기록 → 새 연습/새 일반 런**: 기록만 보이고 옛 그림·방향·점수 표시가 새 런에 남지 않는지 본다.
