- 실제 엔진 프레임의 UI를 별도 카메라로 렌더했다. 입력은 자동 앱 명령이며 OS 게임 창 캡처나 사람의 손 플레이가 아니다. 시험 전용 캡처 코드는 정식 실행본에 넣지 않았다.

- 사람의 리듬 손맛과 소리, 휴대폰 그립·기울임·두 손가락·앱 전환·지연/FPS는 직접 확인이 남는다. 이번에는 판정 폭·점수·피해·저장 규칙을 변경하지 않았다.
