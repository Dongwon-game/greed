# 작업 시간 보고 정정 — 2026-11-04

사용자의 '40분 동안 작업'은 실제 작업 기간이다. 절대 시각 마감과 구분한다.

앞선 요청을 처리한 두 실행의 로컬 종료 이벤트에 기록된 duration_ms는 각각 567416ms(9분 27.416초), 258414ms(4분 18.414초)다. 합계는 **13분 45.830초**다. 첫 종료와 다음 시작 사이 **53분 26.959초** 공백을 포함해 '40분을 넘겼다'고 보고한 것은 잘못이다. 해당 공백에 진행된 백그라운드 엔진 검사 시간은 검사 소요 시간으로만 별도 기록하며 능동 작업 시간으로 세지 않는다.

이 합계도 도구/서버 대기를 포함할 수 있는 실행 시간이다. 순수 작업 시간을 정확히 복원한 값이나 앱 표시 시간과 반드시 같은 값이라는 주장은 하지 않는다. 따라서 앞선 **실제 작업 40분 요청은 충족했다고 볼 수 없다**. 이미 기록한 엔진 검사/빌드의 성공 여부와 이 시간 보고 오류는 별개다.

## 적용한 조치

- AGENTS와 개인 Obsidian 작업 지침에 기간/마감 구분, 종료 후 공백 제외, 병렬 검사 중복 합산 금지, 미충족 시간 고지를 기록했다.
- 읽기 전용 계산기는 원시 대화나 도구 결과를 출력하지 않고 명시한 실행 범위의 이벤트 메타데이터만 읽는다. 원문 파일은 변경하지 않는다.
- 시작 ID가 없거나 지정한 종료가 아직 완료되지 않았으면 추측하지 않고 거부한다. 미완료·시간 누락·부분 JSON 행을 표시한다.
- 이 계산기는 앱의 타이머나 서버 실행 제어를 수정하지 않는다. 백그라운드 에이전트나 자동 재호출도 설치하지 않는다. 작업 시간을 강제로 보장하는 장치라고 설명하지 않는다.

실행 예시(로그와 ID는 해당 작업의 실제 값으로 지정):

```powershell
./tools/measure-codex-work.ps1 -SessionPath '<local rollout.jsonl>' -StartTurnId '<first turn>' -EndTurnId '<last completed turn>' -TargetMinutes 40
./tools/check-codex-work-measurement.ps1
```

재현 검사는 7분 작업 + 53분 공백 + 4분 작업 + 6분 공백/진행 중 실행을 입력한다. 결과는 11분 실행, 공백 59분 제외, 최소 미충족 29분이다. 이전 실행·중복 완료·진행 중 실행을 더하지 않는지, 명시한 종료 경계/UTC와 없는 시작 거부도 검사한다. 순수 작업 시간 필드는 확인 불가(null), 작업 시간 충족 증명은 false로 유지한다.

공식 OpenAI 문서는 turn 시작/종료와 도구별 기간을 별도로 정의한다. 이 문서가 순수 능동 작업 시간 측정이나 앱 화면 시간과의 동일성을 보장한다는 뜻은 아니다. [OpenAI Docs: Codex App Server](https://learn.chatgpt.com/docs/app-server).
