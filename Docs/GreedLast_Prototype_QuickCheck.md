## 이번 추가분 먼저 확인

1. **선택하기 전 안내**: 시작 기프트부터 일반 런을 진행하며 카드의 체력/집중 안내와 선택 직후 실제 변화를 비교한다. 회복 가능하면 `체력 +1`, 상한이면 `체력 상한 유지`다. 현재 게이지가 가득 보여도 기존 회복 상한까지 확장될 수 있다. 집중은 충전/발동/연장/7초 상한 유지를 구분하며, 발동 중인 집중을 부족하다고 `집중 회복` 추천하면 안 된다.
2. **진행 중 집중 보상**: 정확 입력으로 집중을 모아 본다. 기본 Perfect 판정은 실제 `집중+1`→`집중 발동`→발동 중 `집중 유지`를 구분하고 배지에도 거짓 충전 횟수 예고가 없어야 한다. 에디터 F11 상세에서는 실제 `집중 연장 +Ns`가 맞아야 한다. Good로 새 발동하면 `집중 발동`, 기존 집중 중 콤보가 실제 남았을 때만 `집중 연쇄 완충`이다. 빈 콤보에는 완충이 없고 Good는 시간을 늘리지 않는다. 집중 중 Miss도 기존처럼 피해를 받으며, 무적 OFF의 피격을 보호 버그로 오인하지 않는다.
3. **판정 직후 점수 세부**: 에디터 F11에서 회복 직후 조합 보너스와 무한 위협 상승 직후 보너스를 본다. 방금 판정은 채점 당시 체력/위협 기준이며 다음 상태로 다시 계산하면 안 된다. 예를 들어 실제 조합 8점을 회복 후 상태의 12점으로 바꾸면 안 된다. 기본 화면의 `+N점`은 기존처럼 실제 총점 증가량이다. 경계 재현을 위해 개인 조합/포인트를 소모할 필요는 없다.
4. **완주와 저장 연결**: 안정 루트 두 번째 정확 판정 직후의 `회복 대기`/`집중 보상 대기`, 변주의 `집중 보상 대기`를 실제 완주 보상과 비교한다. 이후 일반→원하는 칸 한 번 저장→정비 취소 무소모→실제 무한 두 번/자동 비움은 아래 12단계를 따른다.

자동 대조가 다시 필요할 때만 Play를 중지하고 `Greed Last > Run Choice Health Reward Check`, `Run Choice Focus Reward Check`, `Run Live Focus Feedback Check`, `Run Good Focus Feedback Check`, `Run Resolved Score Feedback Check`를 쓴다. `Run Focus Damage Rule Check`는 개인 데이터 없이 실제 -1 피해 여섯 경우를 확인한다. `Capture Reward Guidance`는 선택 30장·집중 24장·채점 보너스 12장·Good 18장, 총 84장이다. 별도 `Capture Score Boundary Checks`는 상한 화면 24장이며 기본에도 `+5점 / 점수 상한`처럼 실제 증가량만 표시해야 한다. 상한 때문에 개인 점수를 조작하거나 오랜 플레이를 할 필요는 없다. F11/무적/바로가기는 에디터·개발 전용이다.

숫자 검증과 별도로 [기획 체감 다섯 가지](GreedLast_Prototype_PlanCoverage.md)의 직선 주행·함정 가독성·정확 타이밍 이득·제한된 회전·한 판 마무리를 기본 표시에서 먼저 본다. 아래 기존 12단계와 일시정지·재개 앞 여유는 유지한다. 개인 기록이나 보관할 조합을 초기화하지 않는다.

## 처음부터 눌러볼 순서

복기 버튼이 나타나는 기존 일반/무한 결과가 있다면 먼저 눌러 본다. `숙이기 복기`는 2단계, `비틀기 복기`는 3단계부터 시작하며 완료 뒤 `복기 다시 확인`으로 같은 단계에 돌아와야 한다. 기본 연습은 기존 1→2→3 순서다. 이 확인을 위해 진행도나 보관할 조합을 초기화할 필요는 없다.

1. **진입**: 타이틀의 도깨비 소녀와 피라미드 통로 뒤로 입구 로비가 자동으로 열린다. 개발 연결 전환을 누를 필요는 없다.
2. **기초 연습**: 로비의 기초 연습/다시 연습으로 들어간다. 바닥 가시·상단 칼날·측면 날과 점프·숙이기·비틀기가 구분되고, 판정선에 도달할 때 같은 채널을 누른다. 정확/Good/Miss의 수치와 소리가 달라야 한다. 정확/Good의 `+N점`이 총점의 실제 증가량과 같아야 하며 조금 빠른/늦은 Good은 방향이 맞아야 한다. 다른 레인을 한 번 눌러 실제 누른 레인의 Miss와 정답 안내가 분리되는지 본다. 아무것도 안 누른 함정은 `입력 없음`으로 구분되고 타이밍 보정 조언이 없어야 한다.
3. **기본/상세 화면**: 처음부터 기본 표시로 시작한다. 큰 제목, `연습 1/3`과 진행 막대가 분리되어야 한다. 중복 연습 배너는 없어도 시작음은 난다. 에디터 F11로 상세 표시를 열면 실제 빠름·늦음 방향은 그대로이고 판정이 다시 재생되지 않아야 한다. 상세 설명은 게이지를 덮지 않으며 작은 창/태블릿에서도 글자가 잘리지 않아야 한다. 복기 런에서 목표·경로/묶음 보상·새 보정 추천이 함께 나와도 모두 영역 안에 남고 F11 왕복으로 다시 재생되면 안 된다. 다시 F11로 기본 표시로 돌아온다.
4. **정지 메뉴와 보정**: 아래 `일시정지` 또는 Enter/ESC로 멈춘다. 별도 메뉴와 `보정 0ms` 등 현재 적용값이 나오고 뒤의 레인 입력·거리·피해는 멈춘다. 빠름/늦음 조절은 ±20ms씩 즉시 표시되고 0ms 복귀도 바로 반영된다. 포기는 이 메뉴 안에서만 보인다. 바꿔 본 설정은 원래 값으로 돌린다.
5. **재개와 테스트 복귀**: 재개 숫자가 뜰 때 Alt+Tab했다 돌아온다. 다시 정지해 있어야 한다. 새로 재개하면 카운트와 앞 여유 뒤 같은 함정이 이어지고, 대기 시간이 거리나 피해로 더해지면 안 된다. 버튼을 누른 채 F11을 바꿔 손을 떼면 명령은 실행되지 않는다. 상세 화면에서 자동 정지→F11 기본→`함정 재개`를 누르면 다음 함정까지 다시 이어져야 한다. 기본 표시에서 F6 집중 MAX나 무한 PageUp/PageDown 후 F11을 열면 도구 문구가 현재 값과 일치하고, 정지/종료 중 잠긴 도구가 다시 활성화되면 안 된다.
6. **일반 런 시작과 선택**: 연습 결과의 `일반 런으로` 또는 로비의 일반 런을 누른다. 진입 탭이 시작 기프트를 자동 선택하면 안 된다. 시작 기프트→카운트·챕터 배너→첫 함정으로 이어진다. 챕터 뒤 루트를 고르면 기프트가 나오며 빠른 두 번 클릭이 다음 선택까지 건너뛰면 안 된다.
7. **주행과 회전**: `N장 · 통과 수/목표`가 갱신되고 정확 입력의 집중·반격·연쇄 보상이 보여야 한다. 안정 루트에서 피해 후 Good 회복과 정확 묶음 완주의 실제 회복은 `체력 +N`과 게이지가 일치해야 한다. F11 상세의 경로 진행/중단 설명에는 다음 박자와 동작이 남고 작은 창에서도 판정·게이지가 겹치지 않아야 한다. 에디터 F9로 회전 통로를 골라 Q/E를 눌러볼 수 있다. 통로만 제한적으로 기울고 HUD·판정선은 고정되어야 한다.
8. **공명핵과 탈출**: 일반 런의 선택과 함정을 끝까지 통과한다. 빠른 에디터 확인은 F1 무적과 F4 핵 직후/F5 탈출 직전을 쓴다. 마지막 게이트 뒤 클리어 점수·기록과 `저장 기회 1회`가 나타나야 한다.
9. **한 번만 저장**: 결과의 `저장 슬롯 선택`을 누르고 빈 S2/S3 등 원하는 칸을 골라 확정한다. 저장 전에 정상 종료/같은 환경 재실행을 해도 새 후보가 남고 칸을 직접 고르기 전 저장은 잠겨 있어야 한다. 저장/포기 후 다시 열면 같은 후보는 없어야 한다. 다음 새 일반 클리어는 다시 한 번 저장할 수 있다. 덮어쓰기·이름 변경·삭제·저장 포기는 빠른 두 번 클릭으로 확정되지 않아야 한다. 관리 동작은 소모해도 되는 조합에만 시험한다.
10. **무한 준비 취소**: 소모해도 되는 조합을 골라 준비에 들어간다. 진입 탭이나 기프트/유물 연타가 다음 선택·실제 시작까지 넘기면 안 된다. 취소는 2회 그대로이며 별도 실제 시작만 2→1로 줄어야 한다.
11. **두 번째 시작과 자동 비움**: 첫 무한을 정산한 뒤 같은 조합으로 다시 실제 시작한다. 슬롯은 자동으로 비지만 이미 시작한 런은 계속된다. 무적 OFF의 체력 0 종료와 기록 요약을 확인한다. 에디터 End는 테스트 정산용이며 일반 빌드에는 없다.
12. **기록과 재시작**: 로비의 기록 보드에는 실제 기록만 나오고 개발 메모·설정 안내가 섞이지 않아야 한다. 새 기초 연습은 0점·새 체력·새 카운트로 시작하며 이전 피격·결과가 남지 않아야 한다.
