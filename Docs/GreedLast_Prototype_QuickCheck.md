# Greed Last 프로토타입 빠른 확인

기준: 2026-10-01. 기획서의 직선 달리기·회피·리듬 보상과 일반 런→저장→무한 루프를 실제로 확인한다. 날짜별 검증 이력은 [과거 확인 기록](GreedLast_Prototype_CheckHistory.md)에 보존했다.

## 실행

1. Unity Hub에서 `C:\Projectunity\greed last`를 Unity 6.4로 연다.
2. `Assets/Scenes/GreedLast_Boot.unity`를 열고 가로 Game 뷰에서 Play한다.
3. Unity 없이 볼 때는 `Builds/GreedLastPrototype/GreedLastPrototype.exe`를 연다.
4. 기존 진행도와 저장 조합은 유지한다. 이번 확인을 위해 초기화할 필요는 없다. 보관할 조합을 덮어쓰거나 사용 횟수를 소모하지 않는다.

## 이번 변경

- 화면이 처음 표시되는 동안 준비·저장 확인·일반 런의 짧은 연타 보호가 끝나는 문제를 고쳤다. 보호 길이는 그대로 두고 화면 표시가 끝난 뒤에도 남도록 한다. 준비 취소는 무소모이며 저장 1회/실제 시작 2회 규칙은 유지한다.
- 기본/상세 Good의 빠름·늦음 값과 다음 입력 안내는 같은 실제 입력 시각을 사용한다. 판정 문구를 바꿔도 방향이 뒤집히지 않으며 보정값 ±200ms 범위도 검사한다.
- 연습 상세 Miss는 실제 빠름·늦음 또는 입력 없음을 구분한다. 입력 없음에 누른 시각을 만들어 표시하지 않는다. 잘못된 레인은 실제 누른 채널과 정답 채널을 구분한다.
- F11 상세 판정은 기본 화면과 같은 고정 영역 안에 맞춘다. 체력·집중 게이지를 덮지 않으며 상세 진행 문구도 진행 막대 위에 분리한다. 기본 글자 크기·입력 위치와 효과 수명은 유지한다.
- 상세 주행 제목의 두 줄 잘림과 긴 Good의 가로 넘침을 고쳤다. 경로 진행/중단 때 실제 타이밍·보상·다음 동작을 모두 유지하며 세 행으로 정리한다. 미입력은 개발 HUD에서도 가짜 늦음 시각 없이 `입력 없음`으로 표시한다.

### 앞선 실제 입력과 장기 주행

- 잘못된 레인을 누르면 실제 누른 레인에 Miss와 입력 흔적이 나오고, 정답 레인 안내는 따로 유지한다. 주자 반응도 판정 문구가 아니라 실제 입력 레인을 따른다.
- 입력하지 않은 함정에는 빠름/늦음 보정 조언을 만들지 않는다. 20ms 이내 정확 입력은 흔적만 남기며 불필요한 타이밍 교정을 권하지 않는다.
- 가운데 오입력의 긴 Miss 문구는 같은 두 줄 영역에 맞게 표시한다. 정확/Good 크기와 판정 영역·입력 위치·체력 게이지 배치는 유지한다.
- 숨겨진 개발/설정 문구는 기본 주행에서 반복 구성하지 않는다. F11로 열면 최신 집중·위협이 즉시 나오고, 정지 메뉴와 연습 결과의 보정 버튼도 최신 상태를 유지한다.
- 큰 누적 점수와 1,200개 함정/400구간의 연속 진행을 자동 검사한다. 이 길이까지 직접 플레이할 필요는 없다. 자연 실패·최종 기록·새 연습 초기화까지 실제 코어 순서로 확인하며 개인 슬롯은 소모하지 않는다.

### 앞선 실제 보상 추가

- 정확/Good 판정의 두 줄 표시에 실제로 얻은 `+N점`을 넣었다. 연쇄·구간 완주 보상까지 포함하며 기존 점수 규칙은 변경하지 않았다.
- 안정 루트의 Good 회복과 정확 묶음 완주에서 실제로 체력이 늘면 두 번째 줄에 `체력 +N`을 표시한다. 체력 상한으로 늘지 않았을 때는 회복을 표시하지 않는다.
- 20ms보다 작은 정확 입력도 실제 입력 시각으로 흔적을 표시한다. 빠름/늦음 방향을 인간용 판정 문구에서 추측하지 않는다.
- 보정·집중·자동 생성 조작은 이전 판정/소리를 재생하지 않는다. 무적 상태의 실제 새 Miss는 각각 한 번 표시된다. 판정 중 F11은 문구만 전환하며 효과의 수명과 기록은 유지한다.
- 연속 주행의 기록 문구 재계산을 줄였다. 집중 시간과 구간·목표·보상 값은 새 계산과 비교해 보존한다. 개발 낙하 미리보기와 재개 카운트는 이전 판정으로 바뀌지 않는다.

### 앞선 같은 날 변경

- 에디터도 기본 플레이 표시로 시작한다. F11은 필요할 때만 상세 개발 도구를 열며, 기존 설정과 진행도 초기화는 필요 없다.
- 정지 메뉴의 간결한 요약에 현재 보정값을 추가했다. ±20ms 조절과 0ms 복귀가 멈춘 상태에서 즉시 보인다.
- 기본 주행의 작은 긴 설명을 큰 한 줄 진행 표시로 바꿨다. 연습 단계, 일반 챕터/통과 수, 탈출 통과 수, 무한 구간/위협을 구분한다.
- 연습에서는 제목과 겹치던 도입 배너만 숨긴다. 시작음, 동작 안내, 판정선과 타이밍 안내는 유지한다. 일반 챕터/공명핵/무한 위협 배너는 유지한다.
- 기본 주행의 아래 버튼과 Enter는 실제 일시정지를 연다. 카운트·선택 중에는 기존 잠금을 유지한다. 기본 주행의 포기 버튼은 정지 메뉴 안에서만 보이며 선택 뒤로 가기와 결과 저장/로비는 유지한다.
- 에디터 F11 상세 표시에는 기존 자동 생성 정지/시작 조작을 유지한다. F11 전환 때 누르던 입력은 취소하여 바뀐 기능이 손을 뗄 때 실행되지 않는다. 레인 입력 영역, 점수·판정 폭·저장 규칙은 바꾸지 않았다.
- 상세 화면에서 자동 생성을 꺼 놓고 기본 표시로 돌아오면 `함정 재개`가 나온다. 전환만으로 런 상태는 바뀌지 않는다. 버튼을 누르면 활성 함정을 보존하거나 다음 함정을 예약하고, 다시 `일시정지`로 돌아간다.
- 앞선 연속 진행 검증도 유지한다. 12개 합성 타임라인의 연습→일반 탈출→그 결과 기반 무한과 반복 중단/재개 112회를 검사한다.

## 처음부터 눌러볼 순서

1. **진입**: 타이틀의 도깨비 소녀와 피라미드 통로 뒤로 입구 로비가 자동으로 열린다. 개발 연결 전환을 누를 필요는 없다.
2. **기초 연습**: 로비의 기초 연습/다시 연습으로 들어간다. 바닥 가시·상단 칼날·측면 날과 점프·숙이기·비틀기가 구분되고, 판정선에 도달할 때 같은 채널을 누른다. 정확/Good/Miss의 수치와 소리가 달라야 한다. 정확/Good의 `+N점`이 총점의 실제 증가량과 같아야 하며 조금 빠른/늦은 Good은 방향이 맞아야 한다. 다른 레인을 한 번 눌러 실제 누른 레인의 Miss와 정답 안내가 분리되는지 본다. 아무것도 안 누른 함정은 `입력 없음`으로 구분되고 타이밍 보정 조언이 없어야 한다.
3. **기본/상세 화면**: 처음부터 기본 표시로 시작한다. 큰 제목, `연습 1/3`과 진행 막대가 분리되어야 한다. 중복 연습 배너는 없어도 시작음은 난다. 에디터 F11로 상세 표시를 열면 실제 빠름·늦음 방향은 그대로이고 판정이 다시 재생되지 않아야 한다. 상세 설명은 게이지를 덮지 않으며 작은 창/태블릿에서도 글자가 잘리지 않아야 한다. 다시 F11로 기본 표시로 돌아온다.
4. **정지 메뉴와 보정**: 아래 `일시정지` 또는 Enter/ESC로 멈춘다. 별도 메뉴와 `보정 0ms` 등 현재 적용값이 나오고 뒤의 레인 입력·거리·피해는 멈춘다. 빠름/늦음 조절은 ±20ms씩 즉시 표시되고 0ms 복귀도 바로 반영된다. 포기는 이 메뉴 안에서만 보인다. 바꿔 본 설정은 원래 값으로 돌린다.
5. **재개와 테스트 복귀**: 재개 숫자가 뜰 때 Alt+Tab했다 돌아온다. 다시 정지해 있어야 한다. 새로 재개하면 카운트와 앞 여유 뒤 같은 함정이 이어지고, 대기 시간이 거리나 피해로 더해지면 안 된다. 버튼을 누른 채 F11을 바꿔 손을 떼면 명령은 실행되지 않는다. 상세 화면에서 자동 정지→F11 기본→`함정 재개`를 누르면 다음 함정까지 다시 이어져야 한다. 기본 표시에서 F6 집중 MAX나 무한 PageUp/PageDown 후 F11을 열면 도구 문구가 현재 값과 일치하고, 정지/종료 중 잠긴 도구가 다시 활성화되면 안 된다.
6. **일반 런 시작과 선택**: 연습 결과의 `일반 런으로` 또는 로비의 일반 런을 누른다. 진입 탭이 시작 기프트를 자동 선택하면 안 된다. 시작 기프트→카운트·챕터 배너→첫 함정으로 이어진다. 챕터 뒤 루트를 고르면 기프트가 나오며 빠른 두 번 클릭이 다음 선택까지 건너뛰면 안 된다.
7. **주행과 회전**: `N장 · 통과 수/목표`가 갱신되고 정확 입력의 집중·반격·연쇄 보상이 보여야 한다. 안정 루트에서 피해 후 Good 회복과 정확 묶음 완주의 실제 회복은 `체력 +N`과 게이지가 일치해야 한다. F11 상세의 경로 진행/중단 설명에는 다음 박자와 동작이 남고 작은 창에서도 판정·게이지가 겹치지 않아야 한다. 에디터 F9로 회전 통로를 골라 Q/E를 눌러볼 수 있다. 통로만 제한적으로 기울고 HUD·판정선은 고정되어야 한다.
8. **공명핵과 탈출**: 일반 런의 선택과 함정을 끝까지 통과한다. 빠른 에디터 확인은 F1 무적과 F4 핵 직후/F5 탈출 직전을 쓴다. 마지막 게이트 뒤 클리어 점수·기록과 `저장 기회 1회`가 나타나야 한다.
9. **한 번만 저장**: 결과의 `저장 슬롯 선택`을 누르고 빈 S2/S3 등 원하는 칸을 골라 확정한다. 같은 클리어 후보를 다시 저장할 수 없어야 한다. 덮어쓰기·이름 변경·삭제·저장 포기는 빠른 두 번 클릭으로 확정되지 않아야 한다. 관리 동작은 소모해도 되는 조합에만 시험한다.
10. **무한 준비 취소**: 소모해도 되는 조합을 골라 준비에 들어간다. 진입 탭이나 기프트/유물 연타가 다음 선택·실제 시작까지 넘기면 안 된다. 취소는 2회 그대로이며 별도 실제 시작만 2→1로 줄어야 한다.
11. **두 번째 시작과 자동 비움**: 첫 무한을 정산한 뒤 같은 조합으로 다시 실제 시작한다. 슬롯은 자동으로 비지만 이미 시작한 런은 계속된다. 무적 OFF의 체력 0 종료와 기록 요약을 확인한다. 에디터 End는 테스트 정산용이며 일반 빌드에는 없다.
12. **기록과 재시작**: 로비의 기록 보드에는 실제 기록만 나오고 개발 메모·설정 안내가 섞이지 않아야 한다. 새 기초 연습은 0점·새 체력·새 카운트로 시작하며 이전 피격·결과가 남지 않아야 한다.

## 에디터 키

| 동작 | 키 |
| --- | --- |
| 좌 / 중 / 우 | A / S / D, 방향키, Space |
| 회전 통로 | Q / E |
| 일시정지 / 재개 | ESC 또는 P |
| 기본 주행 정지 / 메뉴 재개 / 결과 확정 | Enter |
| 무적 | F1 |
| 기프트 / 유물 / 핵 직후 / 탈출 직전 | F2 / F3 / F4 / F5 |

| 무한 위협 증가 / 감소 | PageUp / PageDown |

테스트 키와 무적·바로가기는 에디터/개발 빌드 전용이다. 비개발 Windows 빌드는 기본 표시와 실제 게임 버튼만 사용한다.

## 모바일에서 추가 확인

1. 가로 방향을 좌우로 바꿔도 기울임 방향이 뒤집히거나 떨리지 않아야 한다.
2. 기울임 ON은 좌우 입력 뒤 중립으로 복귀해야 다음 입력이 한 번 들어간다. OFF는 좌우 탭으로 대응하며 센서 커서/중립 게이트를 숨긴다.
3. 앱 전환→재개, 두 손가락 입력, 노치/크기 변경과 소리 지연은 실제 휴대폰에서 확인한다.
4. 앱 재실행 뒤 소리·진동·기울임·시야 안정·보정 설정이 유지되어야 한다.
