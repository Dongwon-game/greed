# Greed Last 프로토타입 빠른 확인

기준: 2026-10-01. 기획서의 직선 달리기·회피·리듬 보상과 일반 런→저장→무한 루프를 실제로 확인한다. 날짜별 검증 이력은 [과거 확인 기록](GreedLast_Prototype_CheckHistory.md)에 보존했다.

## 실행

1. Unity Hub에서 `C:\Projectunity\greed last`를 Unity 6.4로 연다.
2. `Assets/Scenes/GreedLast_Boot.unity`를 열고 가로 Game 뷰에서 Play한다.
3. Unity 없이 볼 때는 `Builds/GreedLastPrototype/GreedLastPrototype.exe`를 연다.
4. 기존 진행도와 저장 조합은 유지한다. 이번 확인을 위해 초기화할 필요는 없다. 보관할 조합을 덮어쓰거나 사용 횟수를 소모하지 않는다.

## 이번 변경

- 기본 주행의 작은 긴 설명을 큰 한 줄 진행 표시로 바꿨다. 연습 단계, 일반 챕터/통과 수, 탈출 통과 수, 무한 구간/위협을 구분한다.
- 연습에서는 제목과 겹치던 도입 배너만 숨긴다. 시작음, 동작 안내, 판정선과 타이밍 안내는 유지한다. 일반 챕터/공명핵/무한 위협 배너는 유지한다.
- 기본 주행의 아래 버튼과 Enter는 실제 일시정지를 연다. 카운트·선택 중에는 기존 잠금을 유지한다. 기본 주행의 포기 버튼은 정지 메뉴 안에서만 보이며 선택 뒤로 가기와 결과 저장/로비는 유지한다.
- 에디터 F11 상세 표시에는 기존 자동 생성 정지/시작 조작을 유지한다. F11 전환 때 누르던 입력은 취소하여 바뀐 기능이 손을 뗄 때 실행되지 않는다. 레인 입력 영역, 점수·판정 폭·저장 규칙은 바꾸지 않았다.
- 앞선 연속 진행 검증도 유지한다. 12개 합성 타임라인의 연습→일반 탈출→그 결과 기반 무한과 반복 중단/재개 112회를 검사한다.

## 처음부터 눌러볼 순서

1. **진입**: 타이틀의 도깨비 소녀와 피라미드 통로 뒤로 입구 로비가 자동으로 열린다. 개발 연결 전환을 누를 필요는 없다.
2. **기초 연습**: 로비의 기초 연습/다시 연습으로 들어간다. 바닥 가시·상단 칼날·측면 날과 점프·숙이기·비틀기가 구분되고, 판정선에 도달할 때 같은 채널을 누른다. 정확/Good/Miss의 수치와 소리가 달라야 한다.
3. **화면 정리**: 에디터에서는 F11로 기본 화면을 본다. 위에 큰 연습 제목, 그 아래 `연습 1/3`과 진행 막대가 분리되어야 한다. 중복 연습 배너는 없어도 시작음은 난다. F11을 다시 누르면 상세 설명이 바로 돌아온다. 960x540/1280x720/1024x768에서도 글자가 겹치지 않아야 한다.
4. **정지 메뉴**: 기본 주행의 아래 `일시정지` 또는 Enter/ESC로 멈춘다. 별도 메뉴가 뜨고 뒤의 레인 입력·거리·피해는 멈춘다. 포기는 이 메뉴 안에서만 보인다. 소리·보정·시야 안정 설정은 바로 반영된다. 바꿔 본 설정은 원래 값으로 돌린다.
5. **재개 중 창 전환**: 재개 숫자가 뜰 때 Alt+Tab했다 돌아온다. 다시 정지해 있어야 한다. 새로 재개하면 카운트와 앞 여유 뒤 같은 함정이 이어지고, 대기 시간이 거리나 피해로 더해지면 안 된다. 에디터에서 버튼을 누른 채 F11을 바꿔 손을 떼면 명령이 실행되지 않고 새 클릭부터 동작해야 한다.
6. **일반 런 시작**: 연습 결과의 `일반 런으로` 또는 로비의 일반 런을 누른다. 시작 기프트와 경로를 직접 선택한다. 빠른 두 번 클릭이 다음 선택까지 건너뛰면 안 된다. 선택 후 카운트·챕터 배너·첫 함정 순서로 이어진다.
7. **주행과 회전**: `N장 · 통과 수/목표`가 갱신되고 정확 입력의 집중·반격·연쇄 보상이 보여야 한다. 에디터 F9로 회전 통로를 골라 Q/E를 눌러볼 수 있다. 통로만 제한적으로 기울고 HUD·판정선은 고정되어야 한다.
8. **공명핵과 탈출**: 일반 런의 선택과 함정을 끝까지 통과한다. 빠른 에디터 확인은 F1 무적과 F4 핵 직후/F5 탈출 직전을 쓴다. 마지막 게이트 뒤 클리어 점수·기록과 `저장 기회 1회`가 나타나야 한다.
9. **한 번만 저장**: 결과의 `저장 슬롯 선택`을 누르고 빈 S2/S3 등 원하는 칸을 골라 확정한다. 저장 직후 같은 클리어 후보를 다시 저장할 수 없어야 한다. 저장하지 않을 때는 `저장 없이 로비`를 쓴다.
10. **무한 준비 취소**: 소모해도 되는 저장 조합을 골라 무한 준비에 들어갔다 취소한다. 이때는 2회가 그대로여야 한다. 실제 시작만 2→1로 줄어야 한다.
11. **두 번째 시작과 자동 비움**: 첫 무한을 정산한 뒤 같은 조합으로 다시 실제 시작한다. 슬롯은 자동으로 비지만 이미 시작한 런은 계속된다. 무적 OFF의 체력 0 종료와 기록 요약을 확인한다. 에디터 End는 테스트 정산용이며 일반 빌드에는 없다.
12. **기록과 재시작**: 로비의 기록 보드에는 실제 기록만 나오고 개발 메모·설정 안내가 섞이지 않아야 한다. 새 기초 연습은 0점·새 체력·새 카운트로 시작하며 이전 피격·결과가 남지 않아야 한다.

## 에디터 키

| 동작 | 키 |
| --- | --- |
| 좌 / 중 / 우 | A / S / D, 방향키, Space |
| 회전 통로 | Q / E |
| 일시정지 / 재개 | ESC 또는 P |
| 기본 주행 정지 / 메뉴 재개 / 결과 확정 | Enter |
| 무적 | F1 |
| 기프트 / 유물 / 핵 직후 / 탈출 직전 | F2 / F3 / F4 / F5 |
| 집중 MAX | F6 |
| 목표 / 경로 / 동작 / 낙하 확인 | F7 / F8 / F9 / F10 |
| 기본 표시 / 상세 개발 표시 | F11 |
| 무한 위협 증가 / 감소 | PageUp / PageDown |
| 무한 테스트 정산 | End |

테스트 키와 무적·바로가기는 에디터/개발 빌드 전용이다. 비개발 Windows 빌드는 기본 표시와 실제 게임 버튼만 사용한다.

## 모바일에서 추가 확인

1. 가로 방향을 좌우로 바꿔도 기울임 방향이 뒤집히거나 떨리지 않아야 한다.
2. 기울임 ON은 좌우 입력 뒤 중립으로 복귀해야 다음 입력이 한 번 들어간다. OFF는 좌우 탭으로 대응하며 센서 커서/중립 게이트를 숨긴다.
3. 앱 전환→재개, 두 손가락 입력, 노치/크기 변경과 소리 지연은 실제 휴대폰에서 확인한다.
4. 앱 재실행 뒤 소리·진동·기울임·시야 안정·보정 설정이 유지되어야 한다.
