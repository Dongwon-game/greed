## 10월 2일 추가분

1. **상세 선택/결과 입력**: 일반/보충 런의 시작 선택에서 F11을 켠다. 오른쪽 선택 영역의 가장자리까지 눌려야 한다. 안쪽 F7~F10 도구는 선택/종료 결과 중 숨고 주행에서 복원된다. 바깥 F2~F5 바로가기는 유지한다. 경로·기프트·유물 선택에서도 같은 규칙이다. 결과 본문 뒤에 눌리지 않는 도구가 남으면 안 된다. 상세 주행/탈출의 활성 레인 안내도 영역 안에 남아야 한다. 원하지 않는 바로가기는 누르지 않아도 된다.
2. **보충 실패 재시도**: 사용 가능한 저장 조합이 모두 비어 있을 때만 확인한다. 보충 런에서 무적 OFF로 자연 실패한 뒤 로비로 돌아와 `보충 런`을 누른다. 이전 실패의 복기/목표가 이어지고 점수·실수 횟수는 0부터 새로 시작하며 시작 기프트를 다시 골라야 한다. 작은 창의 F11 상세 정지 메뉴에서도 긴 목표·설정이 잘리지 않아야 한다.
3. **보충 중단 재시도**: 보충 런에서 실제 함정 하나 이상을 진행하고 ESC/P 정지 메뉴→로비로 돌아간다. `보충 런 중단`으로 구분되어야 한다. 로비의 `무한 조합 보충`→`보충 런`도 이전 복기/목표를 이어받고 새 선택부터 시작해야 한다.
4. **보충 안내 경유**: 같은 무한 준비 또는 보충 실패/중단 뒤 로비에서 `보충 안내`를 누른다. 다른 빈 칸을 고른 뒤 `보충 런`으로 들어가도 목표가 유지되어야 한다. 안내를 취소하고 새로 열면 지난 안내의 대기 목표가 남지 않아야 한다. 실패/포기/준비/재시도가 새 저장 기회를 만들거나 슬롯을 소모하면 안 된다.
5. **보충 저장 후 재개**: 시험용 보충 런을 클리어하고 원하는 빈 S1/S2/S3에 저장한다. 고른 칸의 `보충 완료`와 무한 준비가 바로 열려야 한다. 준비를 취소해도 2회가 남고, 저장 관리를 다시 열어도 같은 후보를 재저장할 수 없어야 한다. 메뉴에는 직전 주행 입력 파동이 남지 않아야 한다. 일반 유물은 저장하지 않으며 무한 시작 점수는 조합 보너스가 있어 0보다 클 수 있다.
6. **보충 조합 소진 뒤 기록**: 그 시험용 조합으로 무한을 두 번 실제 시작한다. 정비 중에는 소모하지 않는다. 두 번째 시작에 원본 슬롯이 비워져도 현재 런은 계속되고, 체력 0 후 로비에 결과가 한 번 기록되어야 한다. 이후 빈 무한 준비→보충 런은 새 선택부터 시작하며 지난 일반 실패 목표가 되살아나면 안 된다.

보관할 사용 가능 조합이 남아 있으면 2~6번을 위해 일부러 비우지 않는다. 이번 보충 경로는 개인 데이터를 저장하지 않는 자동 검사로도 확인한다. 그때는 1번과 아래 전체 흐름만 먼저 보면 된다.

- 에디터도 기본 플레이 표시로 시작한다. F11은 필요할 때만 상세 개발 도구를 열며, 기존 설정과 진행도 초기화는 필요 없다.
- 정지 메뉴의 간결한 요약에 현재 보정값을 추가했다. ±20ms 조절과 0ms 복귀가 멈춘 상태에서 즉시 보인다.
- 기본 주행의 작은 긴 설명을 큰 한 줄 진행 표시로 바꿨다. 연습 단계, 일반 챕터/통과 수, 탈출 통과 수, 무한 구간/위협을 구분한다.
- 연습에서는 제목과 겹치던 도입 배너만 숨긴다. 시작음, 동작 안내, 판정선과 타이밍 안내는 유지한다. 일반 챕터/공명핵/무한 위협 배너는 유지한다.
- 기본 주행의 아래 버튼과 Enter는 실제 일시정지를 연다. 카운트·선택 중에는 기존 잠금을 유지한다. 기본 주행의 포기 버튼은 정지 메뉴 안에서만 보이며 선택 뒤로 가기와 결과 저장/로비는 유지한다.
- 에디터 F11 상세 표시에는 기존 자동 생성 정지/시작 조작을 유지한다. F11 전환 때 누르던 입력은 취소하여 바뀐 기능이 손을 뗄 때 실행되지 않는다. 레인 입력 영역, 점수·판정 폭·저장 규칙은 바꾸지 않았다.
- 상세 화면에서 자동 생성을 꺼 놓고 기본 표시로 돌아오면 `함정 재개`가 나온다. 전환만으로 런 상태는 바뀌지 않는다. 버튼을 누르면 활성 함정을 보존하거나 다음 함정을 예약하고, 다시 `일시정지`로 돌아간다.
- 앞선 연속 진행 검증도 유지한다. 12개 합성 타임라인의 연습→일반 탈출→그 결과 기반 무한과 반복 중단/재개 112회를 검사한다.

## 이번 추가분 먼저 확인

1. **실행**: 아래 전체 순서의 진입 방법으로 연다. 기존 슬롯과 진행도는 초기화하지 않는다.
2. **복기 진입**: 일반/보충/무한 결과 뒤 로비에 `숙이기 복기` 또는 `비틀기 복기`가 있다면 누른다. 숙이기는 2단계, 비틀기는 3단계부터 시작한다. 복기 목표가 있으면 유지한다. 기존 결과가 없다면 먼저 기본 연습을 확인하고 실제 런의 결과 뒤에 본다.
3. **복기 완료/재시도**: 남은 동작만 끝내면 `복기 연습 완료`와 실제 판정 수가 나온다. 정확은 `복기 다시 확인`, Good은 `정확권 다시`, 오입력/미입력은 `실수 구간 다시`다. 누르면 같은 시작 단계로 돌아간다. 로비 복귀가 새 저장 기회를 만들거나 전체 3축 확인으로 바뀌면 안 된다.
4. **카운트**: 시작과 정지 메뉴의 재개에서 `2→1→GO`를 본다. GO가 체력·집중 게이지를 가리지 않아야 한다. Alt+Tab 뒤에는 다시 정지해 있어야 하고 새 재개 카운트 뒤 같은 함정이 이어진다.
5. **작은 화면/F11**: 에디터 Game 뷰를 960×540으로 보고 F11 상세에서 ESC/P 정지 메뉴를 연다. 긴 복기/보정 문구가 본문 영역을 벗어나거나 재개 버튼을 덮지 않아야 한다. 설정을 바꿔 봤으면 원래 값으로 돌린다. 기본 화면에서도 판정이 게이지를 덮지 않아야 한다.
6. **기존 루프**: 아래 8~12번의 탈출→원하는 칸에 한 번 저장→무한 준비 취소 무소모→실제 시작 두 번째 뒤 자동 비움→기록을 확인한다. 보관할 조합이 아닌 시험용 조합만 사용한다. 실제 폰 기울임/소리 지연은 별도 기기 확인이다.

## 처음부터 눌러볼 순서

복기 버튼이 나타나는 기존 일반/무한 결과가 있다면 먼저 눌러 본다. `숙이기 복기`는 2단계, `비틀기 복기`는 3단계부터 시작하며 완료 뒤 `복기 다시 확인`으로 같은 단계에 돌아와야 한다. 기본 연습은 기존 1→2→3 순서다. 이 확인을 위해 진행도나 보관할 조합을 초기화할 필요는 없다.

1. **진입**: 타이틀의 도깨비 소녀와 피라미드 통로 뒤로 입구 로비가 자동으로 열린다. 개발 연결 전환을 누를 필요는 없다.
2. **기초 연습**: 로비의 기초 연습/다시 연습으로 들어간다. 바닥 가시·상단 칼날·측면 날과 점프·숙이기·비틀기가 구분되고, 판정선에 도달할 때 같은 채널을 누른다. 정확/Good/Miss의 수치와 소리가 달라야 한다. 정확/Good의 `+N점`이 총점의 실제 증가량과 같아야 하며 조금 빠른/늦은 Good은 방향이 맞아야 한다. 다른 레인을 한 번 눌러 실제 누른 레인의 Miss와 정답 안내가 분리되는지 본다. 아무것도 안 누른 함정은 `입력 없음`으로 구분되고 타이밍 보정 조언이 없어야 한다.
3. **기본/상세 화면**: 처음부터 기본 표시로 시작한다. 큰 제목, `연습 1/3`과 진행 막대가 분리되어야 한다. 중복 연습 배너는 없어도 시작음은 난다. 에디터 F11로 상세 표시를 열면 실제 빠름·늦음 방향은 그대로이고 판정이 다시 재생되지 않아야 한다. 상세 설명은 게이지를 덮지 않으며 작은 창/태블릿에서도 글자가 잘리지 않아야 한다. 복기 런에서 목표·경로/묶음 보상·새 보정 추천이 함께 나와도 모두 영역 안에 남고 F11 왕복으로 다시 재생되면 안 된다. 다시 F11로 기본 표시로 돌아온다.
4. **정지 메뉴와 보정**: 아래 `일시정지` 또는 Enter/ESC로 멈춘다. 별도 메뉴와 `보정 0ms` 등 현재 적용값이 나오고 뒤의 레인 입력·거리·피해는 멈춘다. 빠름/늦음 조절은 ±20ms씩 즉시 표시되고 0ms 복귀도 바로 반영된다. 포기는 이 메뉴 안에서만 보인다. 바꿔 본 설정은 원래 값으로 돌린다.
5. **재개와 테스트 복귀**: 재개 숫자가 뜰 때 Alt+Tab했다 돌아온다. 다시 정지해 있어야 한다. 새로 재개하면 카운트와 앞 여유 뒤 같은 함정이 이어지고, 대기 시간이 거리나 피해로 더해지면 안 된다. 버튼을 누른 채 F11을 바꿔 손을 떼면 명령은 실행되지 않는다. 상세 화면에서 자동 정지→F11 기본→`함정 재개`를 누르면 다음 함정까지 다시 이어져야 한다. 기본 표시에서 F6 집중 MAX나 무한 PageUp/PageDown 후 F11을 열면 도구 문구가 현재 값과 일치하고, 정지/종료 중 잠긴 도구가 다시 활성화되면 안 된다.
6. **일반 런 시작과 선택**: 연습 결과의 `일반 런으로` 또는 로비의 일반 런을 누른다. 진입 탭이 시작 기프트를 자동 선택하면 안 된다. 시작 기프트→카운트·챕터 배너→첫 함정으로 이어진다. 챕터 뒤 루트를 고르면 기프트가 나오며 빠른 두 번 클릭이 다음 선택까지 건너뛰면 안 된다.
7. **주행과 회전**: `N장 · 통과 수/목표`가 갱신되고 정확 입력의 집중·반격·연쇄 보상이 보여야 한다. 안정 루트에서 피해 후 Good 회복과 정확 묶음 완주의 실제 회복은 `체력 +N`과 게이지가 일치해야 한다. F11 상세의 경로 진행/중단 설명에는 다음 박자와 동작이 남고 작은 창에서도 판정·게이지가 겹치지 않아야 한다. 에디터 F9로 회전 통로를 골라 Q/E를 눌러볼 수 있다. 통로만 제한적으로 기울고 HUD·판정선은 고정되어야 한다.
8. **공명핵과 탈출**: 일반 런의 선택과 함정을 끝까지 통과한다. 빠른 에디터 확인은 F1 무적과 F4 핵 직후/F5 탈출 직전을 쓴다. 마지막 게이트 뒤 클리어 점수·기록과 `저장 기회 1회`가 나타나야 한다.
9. **한 번만 저장**: 결과의 `저장 슬롯 선택`을 누르고 빈 S2/S3 등 원하는 칸을 골라 확정한다. 같은 클리어 후보를 다시 저장할 수 없어야 한다. 덮어쓰기·이름 변경·삭제·저장 포기는 빠른 두 번 클릭으로 확정되지 않아야 한다. 관리 동작은 소모해도 되는 조합에만 시험한다.
10. **무한 준비 취소**: 소모해도 되는 조합을 골라 준비에 들어간다. 진입 탭이나 기프트/유물 연타가 다음 선택·실제 시작까지 넘기면 안 된다. 취소는 2회 그대로이며 별도 실제 시작만 2→1로 줄어야 한다.
11. **두 번째 시작과 자동 비움**: 첫 무한을 정산한 뒤 같은 조합으로 다시 실제 시작한다. 슬롯은 자동으로 비지만 이미 시작한 런은 계속된다. 무적 OFF의 체력 0 종료와 기록 요약을 확인한다. 에디터 End는 테스트 정산용이며 일반 빌드에는 없다.
12. **기록과 재시작**: 로비의 기록 보드에는 실제 기록만 나오고 개발 메모·설정 안내가 섞이지 않아야 한다. 새 기초 연습은 0점·새 체력·새 카운트로 시작하며 이전 피격·결과가 남지 않아야 한다.

2. 기존 프로필이면 로비에서 `일반 런` 또는 현재 강조된 다음 행동을 누른다. 짧은 상승 스윕과 약한 진동 한 번에 맞춰 작은 주자가 런 크기로 커지고 입구 문틀과 진행 점이 뒤로 사라져 같은 통로로 들어가는 것처럼 보여야 한다. 버튼을 빠르게 두 번 눌러도 두 번째 탭이 시작 기프트를 임의 선택하면 안 된다. 첫 일반 런의 제목은 `시작 기프트 선택`이고, 연습에서 바로 넘어왔다면 연습 완료와 일반 런 시작 문구가 함께 보여야 한다.
3. 시작 선택을 누르면 고른 좌 / 중 / 우 레인만 짧게 밝아지고 해당 레인의 음높이와 확정음이 먼저 난다. 경로에서 기프트로 이어지는 선택을 빠르게 두 번 눌러도 한 번에 한 단계만 확정되어야 한다. 이어서 `CHAPTER 1` 전환음과 배너가 한 박자 분리되어 나타나고, 그 뒤 `2-1-GO`가 시작되어야 한다. 입구 시안이 사라지는 동안 캐릭터 없는 직선 3레인 통로 시안이 자연스럽게 이어지고, 첫 함정이 내려올 때 주자 / 함정 / 판정선이 배경보다 앞에서 읽히는지 본다.
4. 바닥 / 상단 / 측면 함정을 각각 한 번씩 입력한다. 함정이 가시 / 상단 칼날문 / 측면 회전날로 구분되고 `↑ / ↓ / ↔` 기호가 그림 위에서 읽히는지 본다. 입구에서 본 도깨비 소녀가 그대로 달리며 점프 / 숙이기 / 비틀기 동작을 따라가는지, 검은 사각형이나 잘린 발끝 없이 보이는지도 확인한다. 그림 위의 반투명 동작 강조와 `정확 / Good / Miss`의 소리·색·움직임 차이도 본다.
5. 정확권에 가까워질수록 판정선, 목표 레인, 함정 기호가 같은 순간을 가리키는지 본다. 텍스트를 읽지 않아도 누를 타이밍이 보여야 한다.
6. `F9`로 회전 통로를 맞춘 뒤 `Q` 또는 `E`를 누른다. 통로와 배경 일부만 작게 기울고 제목, HUD, 판정선은 고정되어야 한다.
7. `ESC`로 멈춘다. 주변은 어두워지고 별도 메뉴가 떠야 하며, 소리 / 보정 / 진동 / 기울임 설정이 한 화면에서 바뀌어야 한다.
8. `기울임 ON/OFF`를 눌러 버튼 표시가 즉시 바뀌는지 본다. `시야 안정 ON/OFF`도 바꿔 회전 기울기와 Miss 흔들림 강도가 달라지되 판정은 같게 유지되는지 비교한다. 기본 확인은 `시야 안정 ON`으로 돌린 뒤 재개한다.
9. 재개하면 곧바로 함정이 닿지 않고 `2-1-GO`와 앞 박자 여유 뒤 주행이 이어지는지 본다.
   - 1분 이상 주행하거나 창을 잠깐 다른 곳으로 전환한 뒤에도 박자 클릭이 짧게 몰려 나오지 않고 일정 간격으로 복귀하는지 듣는다.
10. `F4`로 공명핵 회수 뒤로 이동하고 탈출 게이트 3칸을 확인한다. 필요하면 `F5`로 탈출 직전으로 이동해 마지막 구간을 통과한다.
11. 탈출 결과 요약과 `저장 기회 1회`를 확인한다. `저장 슬롯 선택`으로 넘어가 좌 / 중 / 우 슬롯을 직접 골라 확정한다. `저장 없이 로비`로 포기할 수도 있다. 저장 직후 같은 클리어를 다시 저장할 수 없어야 한다.
12. 로비에서 저장 조합을 골라 무한모드에 들어간다. 위협 단계가 오를 때 판정 폭과 정확 보상이 함께 변하는지 본다.
13. 무한모드를 정산하고 같은 저장 조합을 다시 한 번 사용한다. 두 번째 사용 뒤 슬롯이 자동으로 비워지고 남은 조합이 있으면 다음 슬롯이 자동 선택되어야 한다.
14. 모든 저장 조합이 비면 로비 버튼이 `보충 런` / `보충 안내` / `무한 조합 보충`으로 같은 재진입 방향을 가리키는지 본다.
15. 기록 보드를 연다. 점수, 거리, 구간, 위협, 콤보, 실수 같은 실제 기록만 보이고 테스트키·설정·그래픽 체크 문구는 섞이지 않아야 한다.

## 모바일에서 추가 확인

1. 가로 방향을 좌우로 바꿔도 회전 통로 기울임 방향이 뒤집히거나 떨리지 않는지 본다.
2. `기울임 ON`에서 폰을 좌우로 살짝 기울인 뒤 중립으로 돌려야 다음 입력이 한 번만 들어가는지 본다.
3. `기울임 OFF`에서는 회전 통로 안내가 좌 / 우 탭으로 바뀌고 센서 커서, 손잡이, 중립 게이트가 숨는지 본다.
4. 앱을 종료해 다시 열어도 소리, 진동, 기울임 설정이 유지되는지 본다.
